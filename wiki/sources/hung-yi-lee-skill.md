# Hung-Yi Lee Skill — 蒸餾李宏毅老師的教學思維

## Summary

不是語錄合集，是把他的「知識與思維框架」蒸餾成可執行的 skill。基於 478 支 YouTube 影片、27 份完整逐字稿、8 個主題頁面、4 份精選研究參考資料，建構 916 節點知識圖譜、10 個概念社群、完整的教學語感 DNA，並經過與老師本人的真實訪談校準。

## 為何做這個 Skill

**問題：**
逐字稿是「倖存者偏差」。它只留下了鏡頭前講出來的東西。

老師為何那樣備課、哪些梗試過又丟掉、他刻意不講什麼——這些字幕裡通通沒有。

**解決方案：**
不是「逆向工程一個老師」，是「逆向工程之後，再回去跟本人對答案」。

## 建構方式（三步）

### Step 1：Fable 5 挖語感

用 Fable 5 對 27 份逐字稿做頻率探勘，挖出原本 skill 沒收錄的招牌語癖：

| 詞彙 | 出現次數 | 備註 |
|------|---------|------|
| 比如說 | 609 次 | 是「舉例來說」的 14 倍 |
| 假設 | 518 次 | |
| 而已 | 160 次 | |
| 就結束了 | 36 次 | |
| 硬 train 一發 | — | 招牌用法 |

**這些不是憑印象加的，是數出來的。**

### Step 2：Fable 5 產生訪談稿

用 Fable 5 跑多 agent workflow，從 SKILL.md、逐字稿、golden/negative 範例裡挖出真正的「風格岔路」，自動生成訪談腳本。

包含：
- 引句反應題
- 反向生成題
- 10 道扎根在真實語料上的 A/B 對比題

### Step 3：本人校準

拿著稿子真的去訪談老師本人。他的回答變成 skill 裡**權威最高的一層**——逐字稿推測出來的東西，只要跟本人說的衝突，一律以本人為準。

## 本人說的三條教學規則

| 規則 | 內容 |
|------|------|
| ① | 內容要有脈絡，不要流水帳 |
| ② | 每堂課要有 punchline（讓人記得住） |
| ③ | 教方法要引導學生想「這個方法是怎麼被想出來的」 |

## 訪談後才知道的修正

| 原本 skill 以為 | 老師本人說 |
|---------------|-----------|
| 開場用「熱騰騰的文件」很生動 | 不會用「熱騰騰」這個詞 |
| 嚇人的事拿日常生活打比方 | 太普通沒梗，會用「更莫名其妙的動漫比喻」 |
| 數字換算成「一個上班日」就夠具體 | 不夠，要讓人感受到代價有多貴、多稀缺 |
| 自己猜測的三條規則 | 親自述說上述三條 |
