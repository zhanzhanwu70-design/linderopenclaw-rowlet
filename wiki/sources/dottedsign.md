# DottedSign

## Summary
eSignature 解決方案，透過 SDK / API / MCP 讓 AI 代理管理簽署流程。Powered by KDAN。

## Repositories

### dottedsign-mcp
MCP server，讓 AI 助手（Claude, ChatGPT）用自然語言管理簽署任務、範本、文件狀態。
- Stars: 120
- Link: https://github.com/DottedSign-Official/dottedsign-mcp

### dottedsign-self-hosted
企業級開源 eSignature 系統，支援 Docker Compose 私有部署（數據主權）。
- Stars: 10
- Link: https://github.com/DottedSign-Official/dottedsign-self-hosted

## Key Features
- AI 驅動的簽署流程自動化
- MCP server 生態整合
- Self-hosted 選項（企業數據主權需求）
- SDK / API 雙重介面

## Relevance
- MCP server 可整合进 OpenClaw agent workflow
- AI + eSignature 是 agentic document workflow 的經典場景
