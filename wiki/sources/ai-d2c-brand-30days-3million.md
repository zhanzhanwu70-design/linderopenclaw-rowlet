# AI幫他30天賺300萬美元：普通人也能學的那套

## Summary
一個普通人在完全不懂普拉提的情況下，用 AI 內容和品牌打法，在 30 天內做出 300 萬美金的 D2C 品牌。

## 案例背景

- 市場：普拉提（Pilates）
- 產品：Grip Socks（防滑襪）
- 結果：30 天，300 萬美金
- 關鍵：用的方法 90% 的人都能學

---

## 五步方法論

### 第一步：用數據找增長市場

用 Google Trends 確認市場在增長。

過去幾年「普拉提」關鍵詞搜索量穩步上升，選擇增長市場而非停滯或下滑的行業。

### 第二步：用 AI 做市場調研挖新品

**方法：**
1. 下載大量 YouTube 普拉提影片
2. 用 YouTube 字幕 + ChatGPT 分析真實用戶需求
3. 找到用戶反復提到、但還沒有大品牌佔領的產品

**實操：**
```
打開 YouTube → 搜索「普拉提女孩的一天」
→ 複製所有字幕 → 餵給 ChatGPT
→ 列出視頻裡提到的早期採用者產品
→ 最後篩選出的就是「防滑襪」
```

**為何值得做：**
用戶在說「I need some grip socks / I forgot my grip socks」，但從不說 Nike 或 Lululemon 的。

**重要洞察：產品認知 > 品牌認知 = 極佳切入時間點。**

### 第三步：身份化品牌（不是產品品牌）

**核心問題：顧客買的不是 Waz，是成為那樣的自己。**

用 ChatGPT 分析目標用戶的核心身份標籤：
→ **Zed Girl**（自律、美學、精致、親生活）

**品牌命名：「光底的」**
- 既點出 Waz 防滑、功能性
- 又巧妙映射普拉提強調的「紮根與穩定感」
- 一個名字，把功能和情感價值都表達了

**視覺風格參考：**
- 高端護肤品牌 Glossier
- 意大利少女服飾 Brandi Mefici
- 藍天、雲朵、粉白的極簡氛圍

### 第四步：專業拍攝建立質感

**方法：**
1. 寫專業生產說明書（顏色、材質、logo 位置）
2. 聯系 20-50 家工廠橫向評估
3. 用多家報價反壓成本
4. 選最專業的一家

**原則：同樣的產品，高級感能讓你多賣三倍價格。**

**拍攝一次性解決：**
- 網站首頁大圖
- 產品白底圖
- 設美素材
- 廣告圖和廣告視頻

### 第五步：三秒公式做爆款內容

**關鍵發現：所有爆款視頻都有共同點——第三秒出現「鉤子」。**

鉤子類型：
- 節奏突然 drop
- 情緒反轉
- 產品揭示
- 視覺切換
- 情節衝突

**案例：**
- 前 2 秒：女孩在 Pilates 機上滑倒
- 第 3 秒：防滑襪功能揭示
- 後面：自然流量爆發

**原則：做到這一點，內容爆的概率提升 10-100 倍。**

### 第六步：精準再營銷廣告

**方法：**
- 對看過視頻 50% 精度的用戶定向推營銷廣告
- 這些人練 Pilates 知道 Grip Socks，但借過他的品牌版本
- 結果：廣告總轉化率高達 **7.19%**
