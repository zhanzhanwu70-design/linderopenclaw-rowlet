## 21:12 heartbeat — 覆核每日資安建議的三個「待 root 項」→ **8/9 已解，7070 仍需 root**

今日 21:05 每日資安建議留了三個「待 root 才能確認」。本輪逐項追查：

**① 高位 port owner — 已確認（不需 root）**：`rpcinfo -p` 對出 57527/45825/53771=**mountd**、32961=**status**、38307=**nlockmgr**、43517/41799/40357/37429=rpcbind 動態 port → **8 個「不明高位埠」全是 nfs-server/rpcbind 一套**，不是 8 個獨立服務。

**② sshd 有效設定 — 已確認（不需 root）**：`PasswordAuthentication` 與 `PermitRootLogin` 兩行皆註解 → 有效值為 Ubuntu 22.04 預設；且 `authorized_keys` 有 5 條 ssh-ed25519（~/.ssh 700 / authorized_keys 600）→ **關密碼驗證安全，不會鎖死自己**。

**③ 7070 — 唯一仍未解，需 root**：`/proc/net/tcp` 顯示 uid=0、inode 24913/24914、LISTEN；非 root 讀不到 root process 的 `/proc/<pid>/fd` → inode 比對失敗。已排除 systemd unit（無 7070 設定）、docker（無映射）、Tailscale serve/funnel（無）、cloudflared（其 metrics 在 **127.0.0.1:20241**，僅 loopback）。curl `/` 與 `/metrics` 皆 **Empty reply from server**（非 HTTP 服務）。→ 仍需 `ss -tlnp | grep 7070` 或 `fuser -n tcp 7070`。

**補充**：cloudflared（systemd pid 7133）跑 tunnel，token 檔 `/etc/cloudflared/token`（未讀內容）。開機 41 天、x11vnc 亦 41 天未重啟 → **今日方案的「停 x11vnc」會直接斷掉遠端桌面通道，必須先確認 Linder 是否在用**。
