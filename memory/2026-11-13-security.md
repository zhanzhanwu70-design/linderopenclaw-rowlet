### 頭條 1：OpenSSH「SSHole」CVE-2026-123158（CVSS 8.1）— 公布 40 小時內即被開採，11-09 進 KEV<!-- project: github.com/zhanzhanwu70-design/linderopenclaw-rowlet -->
- 11-05 OpenSSH 10.6p2 修補；攻擊者在 **40 小時內**開始利用（GreyNoise event tracker）。
- 觸發條件：**musl libc**（Alpine 與多數 container base image）+ **未啟用 PAM** + 密碼驗證開啟 + 目標帳號密碼欄為 `*`（key-only）。Debian/Ubuntu（glibc）**不受影響**。

- **本機判定**：Ubuntu 22.04.5 + glibc + `UsePAM yes` → **不適用**；但本機 sshd **暴露 0.0.0.0:22** 仍值得收斂（見方案 C）。
