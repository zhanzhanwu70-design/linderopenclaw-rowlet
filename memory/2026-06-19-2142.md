## 🌿🦉 Minerva HC #23：Attention Bias（注意力偏誤）

### 定義

**Attention Bias（注意力偏誤）** — 認知資源在分配時**系統性偏向某些線索、忽略其他線索**，導致後續的歸納、預測、判斷全部建立在**扭曲的資訊子集**上。

與 #24 Confirmation Bias 的差別（容易混淆）：
- **#23 Attention Bias**：**進入視野**的資訊就不對（看不見某些東西）
- **#24 Confirmation Bias**：進入視野後**篩選/解讀**的方式不對（看見了但不採信反面）

形式符號：$\Pr(\text{considered} \mid \text{all evidence}) \neq \text{uniform}$ — 對所有可用證據的「考慮機率」不均勻。

> **一句話**：注意力是認知的入口，**入口被污染，後面再好的模型也救不回來**。#22 Prediction 給你預測能力，#23 提醒你**你看見的世界不等於真實世界**。

---

### 為什麼這個 HC 重要？

注意力是**所有認知的瓶頸**：人類每秒接收 ~10⁷ 位元感官資訊，但工作記憶只能處理 ~50 位元/秒。**這個 10⁵:1 的壓縮比是所有偏誤的源頭**——你以為自己在「看事實」，其實你只在看「注意力允許的事實」。

| 場景 | 注意力偏誤的災難 | 解方 |
|------|------------------|------|
| 醫療診斷 | 罕見病被當流行病治療（availability） | 強制基礎率 + 鑑別診斷清單 |
| 投資 | 只看新聞頭版（recency + salience）| 看長期總經指標 |
| 招聘 | 第一印象 30 秒定生死（anchoring + halo）| 結構化面試 + 盲評 |
| 司法 | 媒體報導影響陪審團（spotlight effect）| 證據隔離審判 |
| 政策 | 危機事件驅動立法（聚焦事件）| 反事實分析 + long-term impact |
| 軟體 | 監控儀表板紅色警示吸引注意 | 設計分層告警 |
| 國際 | 烏克蘭 2022 入侵被低估 | 多源情報 + 反方預測 |
| LLM | Context window 前後段被忽略 | 結構化 prompt + 重複關鍵 |

> **核心洞察**：注意力偏誤是**最隱形的偏誤**——你不知道你沒看見的東西。要對抗它，必須**主動結構化你的資訊攝取流程**。

### 注意力偏誤的十一大類型

| 類型 | 機制 | 經典實驗 / 範例 | 校正 |
|------|------|----------------|------|
| **選擇性注意（Selective attention）** | 只注意符合預期的資訊 | Cocktail party effect | 結構化檢查清單 |
| **可得性捷思（Availability）** | 最近/生動/情緒強的事件被高估 | Tversky & Kahneman 1973 | 強制度量 + base rate |
| **突現效應（Salience）** | 醒目資訊被過度權重 | 紅色按鈕 vs 灰色按鈕 | 設計中性化 UI |
| **焦點效應（Spotlight / Focus）** | 高估自己被注意的程度 | 「穿新衣」實驗 | 求外部視角 |
| **遺忘基率（Base rate neglect）** | 忽略基本率 | 經典「計程車問題」| 先寫 base rate |
| **頻道效應（Channel effect）** | 從單一資訊源取得片面資訊 | 只看 Twitter 判斷社會 | 多元來源 |
| **新奇偏誤（Novelty bias）** | 新聞 > 持續事實 | 新政策報導 vs 政策長期影響 | 拉長時間軸 |
| **負面偏誤（Negativity bias）** | 壞消息權重 > 好消息 | 媒體 80% 壞消息 | 平衡採樣 |
| **情緒偏誤（Emotion-driven attention）** | 恐懼/憤怒放大注意 | 9/11 後飛安過度反應 | 風險 = 機率 × 影響 |
| **確認偏誤（注意層面）** | 找支持自己觀點的資訊 | Klayman 1987 | red team 搜尋 |
| **時間注意力（Temporal attention）** | 短期被放大、長期被忽略 | 季度報表 vs 10 年趨勢 | 預先宣告評估點 |

```python
def detect_attention_bias(observation, all_evidence, salience_signals):
    """
    計算「你看到的 vs 全部可見的」差異
    """
    seen = set(observation)
    unseen = set(all_evidence) - seen
    
    bias_signals = {
        "availability": any(recent in seen for recent in salience_signals["recent_events"]),
        "salience": any(visually_striking in seen for visually_striking in salience_signals["high_contrast"]),
        "negativity": any(neg in seen for neg in salience_signals["negative_news"]),
        "base_rate_neglect": "base_rate" not in observation,
        "channel_monoculture": len(salience_signals.get("sources", [])) == 1,
    }
    
    return {
        "n_seen": len(seen),
        "n_unseen": len(unseen),
        "coverage_rate": len(seen) / len(all_evidence) if all_evidence else 0,
        "bias_signals": bias_signals,
        "warning": "若 coverage_rate < 0.5 且 channel_monoculture=True：高度警覺"
    }
```

#### 方式一：結構化注意力審計（5 步流程）

| 步驟 | 動作 | 輸出 |
|------|------|------|
| **1. 列全集合** | 寫下所有**理論上應該看見**的證據 | evidence_universe |
| **2. 列已看集合** | 寫下我**實際看見**的證據 | evidence_seen |
| **3. 算缺口** | unseen = universe − seen | gap_list |
| **4. 分類缺口** | 為何沒看見？（不可知/忽略/逃避/不顯眼）| gap_taxonomy |
| **5. 主動補課** | 為每個缺口指定查詢動作 | next_actions |

> **核心**：看不見的東西，**寫下來**才算看見。口頭說「我有考慮到」= 自欺。

#### 方式二：注意力分配均衡設計

| 原則 | 描述 | 應用 |
|------|------|------|
| **多源原則** | 同一事實，至少 3 個獨立來源 | 新聞事件、政策、科學結論 |
| **時間平衡** | 短期 + 長期 + 歷史 + 預測 | 季度 / 年度 / 10 年 / 30 年 |
| **觀點對沖** | 至少 1 個反向觀點 | 投資、選舉、政策 |
| **量化優先** | 數字 > 故事，分布 > 點 | 媒體偏故事 |
| **基率優先** | 寫下長期 base rate 再看個案 | 流行病、投資、法律 |
| **結構化攝取** | 預先定義要看的欄位 | CRM 報表紙欄位 |
| **被動降噪** | 主動減少通知、警示、廣告 | Do Not Disturb |
| **沉沒時間預算** | 每天限制「雜訊源」時間 | Twitter 30 min/day |

```python
def balanced_attention_check(sources, time_buckets, viewpoints):
    """
    多維度注意力均衡檢查
    """
    coverage = {
        "source_diversity": len(set(sources)) / len(sources) if sources else 0,
        "time_coverage": len(set(time_buckets)) / 4,  # 假設 4 個時間段
        "viewpoint_diversity": len(set(viewpoints)) >= 2,
    }
    
    red_flags = []
    if coverage["source_diversity"] < 0.5:
        red_flags.append("來源過於單一")
    if coverage["time_coverage"] < 0.5:
        red_flags.append("時間範圍太窄")
    if not coverage["viewpoint_diversity"]:
        red_flags.append("缺少反向觀點")
    
    return {
        "coverage": coverage,
        "red_flags": red_flags,
        "verdict": "OK" if not red_flags else "需重新分配注意力"
    }
```

#### 方式四：注意力偏誤的量化測量

```python
def attention_audit_experiment(stimuli, target_features, n_trials=100):
    """
    心理物理學標準化注意力偏誤測量
    """
    import numpy as np
    
    # 對每個 feature，測量反應時間與準確度
    results = {}
    for feature in target_features:
        congruent_trials = [t for t in stimuli if t["congruent"] == feature]
        incongruent_trials = [t for t in stimuli if t["incongruent"] == feature]
        
        congruent_rt = np.mean([t["rt"] for t in congruent_trials])
        incongruent_rt = np.mean([t["rt"] for t in incongruent_trials])
        
        # 注意力偏誤指數 (越大越偏)
        bias_index = incongruent_rt - congruent_rt
        results[feature] = {
            "congruent_rt": congruent_rt,
            "incongruent_rt": incongruent_rt,
            "bias_index_ms": bias_index,
            "interpretation": "顯著偏誤" if bias_index > 50 else "正常"
        }
    
    return results

# 範例：Stroop task（顏色 vs 文字）
# 紅色字寫「綠」 → 反應時間慢 = Stroop 效應 = 注意力衝突
```

### 注意力偏誤的現代變體（社群媒體 / AI 時代）

| 變體 | 機制 | 後果 | 解法 |
|------|------|------|------|
| **演算法放大** | 平台推薦放大你已點擊的東西 | Filter bubble / Echo chamber | 主動取消追蹤 + 多元 feed |
| **Doomscrolling** | 負面偏誤 × 無限滾動 | 焦慮、決策癱瘓 | 時間上限 + 內容審核 |
| **通知風暴** | 注意力被外來打斷 | Deep work 失效 | 通知分級 + Do Not Disturb |
| **Dopamine hijack** | 短影音設計多巴胺 | 長期注意力下降 | 環境設計阻擋 |
| **AI 摘要偏誤** | LLM 摘要偏某些觀點 | 偏食的二手知識 | 看多個 AI 摘要 + 原文 |
| **Context window effect** | LLM 對 context 中段關注低 | Lost in the middle | 結構化 + 重要資訊重複 |
| **RAG ranking bias** | 檢索結果按相關性排序，前 3 條被過度權重 | 漏掉長尾事實 | 看完整排序 + 強制遍歷 |
| **Sycophancy attention** | LLM 偏向用戶先驗 | 確認偏誤 × 注意力 | 強迫 LLM 給反方 |

```python
def detect_llm_attention_bias(prompt, llm_output, key_facts):
    """
    LLM 注意力偏誤偵測：給定 prompt 中的關鍵事實，模型有沒有忽略？
    """
    missed = []
    for fact in key_facts:
        if fact.lower() not in llm_output.lower():
            missed.append(fact)
    
    coverage = 1 - len(missed) / len(key_facts) if key_facts else 0
    
    return {
        "n_facts": len(key_facts),
        "n_missed": len(missed),
        "coverage": coverage,
        "missed_facts": missed,
        "verdict": "LLM 注意力缺失" if coverage < 0.7 else "OK"
    }
```

### 反思問題

1. 我**實際看見**的證據 vs **理論應該看見**的證據，差多少？寫下來
2. 我的**資訊源**有幾個獨立管道？≥3 才算多源
3. 我**最近**的判斷中，有沒有「最近事件被放大」？抽 3 個檢查
4. 我有沒有**主動找反證**？還是只看到支持自己觀點的資訊
5. 我**今天**花了多少時間在「重要但不緊急」的事 vs「緊急但不重要」的事？（艾森豪矩陣）
6. 我的 LLM prompt 中，**關鍵事實**有沒有被放在最顯眼位置？前 / 中 / 後？
7. 我**今天**有沒有被通知打斷 deep work 超過 3 次？
8. 我**昨天**做的判斷，**今天**重新看，會改變嗎？（時間距離校準）
9. 我有沒有**逃避**某些資訊？（例如不看帳單、健檢報告）
10. 我有沒有**迷戀**某些資訊源到失去多元？（例：只看一個人、一個頻道）

### 注意力偏誤的極限（誠實補充）

| 限制 | 說明 |
|------|------|
| **注意力是有限資源** | Herbert Simon 1971：資訊豐富 = 注意貧乏 |
| **演化適應** | 注意力偏誤是**為生存設計的**（戰或逃）— 不能完全消除 |
| **個體差異** | ADHD、自閉症、注意力訓練者基線不同 |
| **不可能全知** | 物理上你無法看完所有資訊，**只能結構化取捨** |
| **注意力設計** | 環境設計 ≠ 個人意志，系統改變比個人修煉有效 10x |
| **可訓練但有限** | 冥想能改善但不能根除 |
| **注意力 = 權力** | 誰控制你的注意力來源，誰控制你的判斷（Tim Wu, *The Attention Merchants*） |
| **AI 注意力** | LLM 的 attention ≠ 人類注意力，機制完全不同 |

> **平衡**：**承認注意力偏誤是預設狀態**，**設計環境讓它難以發生**，比「用意志力克服」更有效。**注意力衛生 = 現代決策素養的根基**。

**為何這個 HC 重要**：#22 Prediction 給你「預測未來」的能力，#23 Attention Bias 提醒你**你預測的基礎是「扭曲的資訊子集」**。沒有 #23 的注意力素養，你做的 #22 預測是**沙堆上的城堡**——做得再精緻，基礎崩了就全倒。

> 「**最近**發生的事有沒有被過度放大？」
