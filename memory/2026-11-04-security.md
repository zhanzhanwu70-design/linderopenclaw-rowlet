### 今日頭條 4：**Device-code phishing 與 ConsentFix**（MFA 繞過的 OAuth 手法）
- **Skyw4lker**：用 Microsoft OAuth **device code flow** 釣 M365 token，目標為美國製造業／科技／醫療。
- **ConsentFix**：瀏覽器式釣魚，騙出 OAuth authorization code 換取 access/refresh token → **MFA 完全被繞過**。
- 產後效應更麻煩：攻擊者用取得的 token **自行註冊裝置、取得 PRT（Primary Refresh Token）** → 從「單次登入」升級為「長期駐留」。
- 防線建議：**停用 device code flow（一般使用者）**、對 OAuth app 與裝置註冊設條件式存取、監看 token 發給非公司裝置的行為。
