### 論文：REAL: A Reasoning-Enhanced Graph Framework for Long-Term Memory Management of LLMs
- **arXiv**: 2606.10694
- **作者**: Keer Lu, Liwei Chen, Guoqing Jiang, Zhiheng Qin, Yunhuai Liu, Wentao Zhang (PKU + Kuaishou)
- **Submitted**: June 9, 2026
- **PDF**: `/home/node/.openclaw/workspace/llm-wiki/raw/references/papers/ai/2606.10694_REAL_long_term_memory.pdf`
- **Wiki Source**: `wiki/sources/REAL Reasoning-Enhanced Graph Framework for Long-Term Memory.md`

### 核心問題
LLM 的 context window 有限，長期互動會話的記憶管理是關鍵挑戰。現有系統有三個問題：
1. **C1**: Flat text organization → 缺乏明確的 memory links，無法多跳檢索
2. **C2**: Destructive updates → 直接覆蓋事實，抹除演化軌跡
3. **C3**: Query-agnostic retrieval → 被動、缺乏 counterfactual 推理能力

### REAL 的解法
1. **Temporal Directed Property Graph**: 每個 atomic fact = (h, r, t, τ, c, ι)
   - h: head entity, r: relation, t: tail entity
   - τ: valid-time interval
   - c: confidence score
   - ι: exploration intent (CAUSAL, TEMPORAL...)
2. **Non-Destructive Updates**: 單值關係終止舊版本並行保存，多值關係並存新舊版本
3. **Hybrid Beam Search**: semantic evaluator 評估 query relevance + logical coherence + answer sufficiency
4. **Counterfactual Inference**: 透過對稱/同義/子集等隱式邏輯關係修復不可靠檢索

### Key Result
22.72% 平均提升（相較 flat-text、graph-based 和 SOTA memory management 方法）
