### Top 5 discussion points

1. **Paradigm shift**: 從「store and retrieve」到「environment and explore」。Context construction 不是保留什麼，而是讓 model 寫程式構造 working view。
2. **`S_t = (L_t, P_t, V_t)` decomposition**: Event Log (lossless ground truth) + Durable storage + Persistent Python kernel — 比 MemGPT 的分層 paging 更根本。
3. **Eviction ≠ loss**: 工作 view 縮小但 ground truth 保留。Headline index (O(k log_k n)) 取代 keyword-only search，解決「忘了 wording 就找不到」問題。
4. **Ablation story**: Lossy summarization 在 BEAM_10M 從 73.1 跌到 19.9 (-73 points)。Event Log 是最有價值的 component，不是 REPL，不是 index。
5. **SOTA + beats by big margin**: BEAM_10M 73.1 (+5.1 over best); LOCA_256K 86.7 (**+37.4** over best published long-horizon agent)。Cross-backbone spread 64 points on LOCA_256K 顯示蒸餾 frontier traces 是有搞頭的方向。
