### 選讀論文：LeanMem

**Paper**: LeanMem: Simple and Efficient Long-Term Memory for LLM Agents
**arXiv**: 2608.03463
**Authors**: Yuxin Liao, Le Wu, Min Hou, Hao Liu, Han Wu, Zishu Wang
**Submitted**: 2026-08-04

**Core insight**: 對話資訊本質上並不相同，不應該用統一 pipeline 處理。提出三類差異化儲存：
- **Profile memory**：穩定用戶屬性/偏好 → 緊湊結構化，不做 evolution
- **Event memory**：動態狀態變化 → 帶時間錨，selective evolution
- **Record memory**：密集細節 → 輕量 index + 指標回原始對話

**Key numbers**:
- Accuracy: +15.1 points over strongest baseline
- Construction tokens: 17.24× reduction
- Inference tokens: 8.41× reduction

### 討論重點（最值得團隊關注的 5 點）

1. **資訊類型差異化原則**：不是設計更好的 schema，而是先問「這段資訊是什麼類型」。穩定的存 profile，變化的存 event，密集的存 record。這個原則可以立即應用到 Rowlet 的 heartbeat 寫入邏輯。

2. **Query-conditional retrieval**：根據問題類型動態分配 retrieval budget，而不是對每個問題用相同策略。這與我們目前用 graphify query 的方式相容，可以增加 budget-aware 的查詢規劃。

3. **Valley-depth topic segmentation**：用 cosine similarity + valley depth 自動偵測 topic boundary，可以自動識別 daily memory 中的 topic shifts，不需要手動 session boundary。

4. **Source-grounded record memory**：record memory 保留指標回原始對話的能力對於需要 trace evidence 的場景很有價值，符合我們 wiki sources 的設計哲學。

5. **Irreversibility 問題的根本解法**：LeanMem 解決的是「壓縮後 fine-grained evidence 無法恢復」的問題。不同於 ACE 的雙層 lossless storage，LeanMem 的解法是「根據資訊類型決定保留方式」——dense detail 用 index 回溯，而不是壓縮。
