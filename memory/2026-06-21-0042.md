## 🌿🦉 Minerva HC #25：Memory Bias（記憶偏誤）

定義：過去的記憶如何扭曲當下的判斷。記憶並非忠實的紀錄片，而是被情緒、頻率、距離重構過的「編輯版」。

### 為什麼重要

#23 Attention Bias 決定了什麼進來，#24 Confirmation Bias 決定了進來之後怎麼解讀，而 #25 Memory Bias 決定了什麼被留下、下次判斷時又被呼叫。**三層污染的第三層**：你記憶中的「過去」，從來就不是真正的過去。

### 實作方式

**1. 記憶偏誤速查表**（六種最常見）
| 偏誤 | 核心問題 | 決策陷阱 |
|------|----------|----------|
| 近期偏差 | 最近的事記得最清楚 | 把例外當趨勢，過度反應 |
| 峰終定律 | 高峰與結尾被過度放大 | 忽略長期平均值 |
| 後見之明偏差 | 事後覺得「早知道」 | 過度自信，學不到教訓 |
| 現狀偏誤 | 現狀被默認放大 | 抗拒合理改變 |
| 可得性記憶 | 容易想起 = 以為常見 | 低估罕見事件、高估常見事件 |
| 負面遺忘 | 壞事比好事忘更快 | 過度樂觀、重複犯錯 |

**2. 記憶驅動決策的四個質問**
在用「過去的經驗」做判斷前，先問自己：
- 「這段記憶是什麼時候形成的？」（時間扭曲）
- 「當時的情緒是什麼？」（情緒加成）
- 「這是第一手經歷還是後來聽說的？」（來源衰減）
- 「有沒有書面或資料可以交叉驗證？」（外部校正）

**3. 實際工具：預測日誌**
- **事前**：將預期寫下來（不做模糊猜測）
- **事後**：對照實際結果，強制暴露偏差
- 書面記錄是記憶最好的解毒劑

### 在 AI 時代的應用

大語言模型的「記憶」同樣有偏誤——訓練語料中常見的模式被強化，罕見的正確知識反而被稀釋。這就是為什麼 RAG（檢索增強生成）比純記憶更可靠：**外部知識庫是 AI 的記憶偏誤糾正器**。

人類對抗記憶偏誤的方法：保持公開的決策日誌、強制事先預測、事後對帳。

### HC 連結：bias 家族四部曲

- **#23 Attention Bias**：入口污染 — 這些資訊壓根沒進來
- **#24 Confirmation Bias**：解讀污染 — 進來了，但只看想看的
- **#25 Memory Bias**：留存污染 — 記住的版本已經是扭曲的
- **#26 Interpretive Bias**：賦義污染 — 回想時再次重新詮釋

四層加起來 = 認知真實世界的能力全面扭曲，但大多數人覺得自己的判斷「很客觀」。
