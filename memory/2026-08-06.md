- **Authors**: Aman Mehta, Anupam Datta (CMU)
- **arXiv**: 2606.22953
- **儲存位置**: `raw/references/papers/ai/2606-plans-dont-persist/`

### 最值得討論的重點

1. **Plan Signal Decay（計畫信號衰減）**
   - 用 replay pairing 方法：對比有/無 plan 時的 hidden-state cosine distance
   - Llama-3.1-70B：plan signal 在 1 step 後衰減 4.1x
   - HotpotQA：衰減 12.4x
   - **核心發現**：LLM 不會把 plans 編碼成持久 hidden state，而是依賴 plan 留在 context 內

2. **Reasoning-Trace Confound（推理軌跡混淆）**
   - Reasoning models（如 R1）的 `<think>` 區塊會重新推導 plan content
   - 標準 stripping 會殘留 plan evidence
   - **Strict stripping**：只從 stripped run 移除 `<think>` 區塊，復原 +163% signal

3. **Cross-Model Probe Transfer（跨模型探針遷移）**
   - Llama-trained probe → DeepSeek-R1-Distill-Llama-70B: AUROC 0.748
   - R1-specific probes: AUROC 1.000
   - **結論**：R1 把 plan signal 編碼在不同的 hidden-state direction

4. **Compression Stress Test（壓縮壓力測試）**
   - Naive plan eviction → ALFWorld 成功率 -34.7pp
   - Probe-gated re-surfacing 無法完全恢復
   - **核心結論**：Context management is load bearing, but plan protection alone is not enough
