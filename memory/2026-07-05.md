## 23:00 UTC (07:00 Taiwan 2026-07-06) — 每日論文討論

### 選讀論文
**ECHO: Prune to Act, Trace to Learn with Selective Turn Memory in Agentic RL**
arXiv:2606.31650 | Xie et al. (Peking U. + Baidu) | 2026-06-30

### 主題：Agent 上下文處理（Context Processing）

### 核心發現（值得討論的 5 個重點）

1. **Context management 和 credit assignment 必須 joint design**
   - 現有方法（truncation/summarization/retrieval）只解決了 acting 瓶頸，但犧牲了 source-addressability
   - 當 outcome-based RL 無法追踪 credit 到支撐成功的原始 evidence turns時，學習信號被稀釋（dense assignment spreads advantage over redundant searches / incidental reasoning）

2. **Source-indexed memory record 是核心創新**
   - 每個完成的 tool-use turn 被壓縮成：local finding（關鍵發現）+ source-turn pointer（指向原始環境 turn）
   - Distant history 維持為 non-collapsing set → 避免 rolling summary 導致的 topic mixing 和 provenance loss

3. **History collapse 的 hidden cost**
   - 實驗發現 rolling summarization 看似讓 rollouts 變長，但同時導致 turn proliferation、larger trajectory volume、slower training
   - 原因：summary 丟失 provenance，credit 乱撒，policy 學到的是 summary-generation 行為而非 evidence-gathering 行為

4. **Provenance-guided credit routing**
   - 同一 source indices 同時服務於 acting（reconstruction）和 learning（credit routing）
   - 路由路徑：final answer → selected historical source turns → memory findings → memory-selection actions
   - 這樣 outcome advantage 只流向真正支撐成功答案的 evidence 和 selection 動作

5. **實驗驗證**
   - BrowseComp-Plus: **43.4%** vs GRPO 28.9% vs SUPO 36.1%
   - 更少 turns、更低 trajectory volume（相對於 SUPO）
   - Zero-shot generalization 到 multi-objective QA、code generation、information-seeking（dense + MoE backbones）
