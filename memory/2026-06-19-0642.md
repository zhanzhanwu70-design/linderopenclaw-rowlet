## 🌿🦉 Minerva HC #18：Significance（顯著性）

### 定義

**Significance** — 區分「**統計顯著**（statistical significance）」與「**實質顯著**（practical significance）」的能力。它問的不是「這個結果是真的嗎？」，而是雙重判斷：

> **① 這個結果有可能是雜訊造成的嗎？**（統計顯著性）
> **② 就算不是雜訊，這個結果在現實中重要嗎？**（實質顯著性）

**核心警句**：**「統計顯著 ≠ 實質顯著」**。一萬人的 A/B 測試讓按鈕顏色讓 CTR 從 5.00% 升到 5.01% — p < 0.001，統計上極顯著；商業上零意義。

---

### 為什麼這個 HC 重要？

Fisher 與 Neyman-Pearson 兩派吵了 90 年的「顯著性到底是什麼」到今天還沒結論。但實務上的災難是清楚的：

| 災難模式 | 後果 |
|---------|------|
| 把 p < 0.05 當真理 | 大量 false positive 進入文獻（replication crisis）|
| p > 0.05 =「無效果」 | 錯失真實效應（type II error）|
| 大樣本 = 萬能 | 任何微小差異都「顯著」|
| 小樣本 = 安全 | 看不到真實效應 |
| 多重檢定不校正 | 100 個假說隨機會有 5 個 p < 0.05 假陽性 |

一句話：**p 值是「資料在虛無假設下多極端」，不是「假設為真的機率」**。把 p 當成假說的機率，是 p 值被誤用的最常見原因。

---

### 核心觀念速查

| 概念 | 公式符號 | 意思 | 常見誤用 |
|------|---------|------|---------|
| **p-value** | $P(D \mid H_0)$ | 在 H₀ 為真下，看到此資料（或更極端的）機率 | 當成 $P(H_0 \mid D)$ |
| **α** | — | 拒絕 H₀ 的容忍假陽性率（常設 0.05）| 當成「H₁ 為真機率」|
| **Effect size** | d, r, η², Cohen's f | 效應量級（標準化差異）| 忽略，導致「顯著但無意義」|
| **Power (1−β)** | — | 偵測真實效應的機率（常需 ≥ 0.80）| 沒做 power analysis |
| **Type I error** | α | 拒絕真的 H₀（假陽性）| 以為 5% = 5% 假說是錯的 |
| **Type II error** | β | 接受錯的 H₀（假陰性）| 用 p > 0.05 證明「無效」|
| **Bonferroni** | α/k | 多重比較校正：把 α 除以檢定次數 | 過度保守 |
| **FDR (BH)** | — | 控制「假陽性佔所有顯著結果的比例」| 誤用為「總錯誤率」|
| **p-hacking** | — | 一直收集資料直到 p < 0.05 | 嚴重膨脹顯著性 |
| **HARKing** | — | 事後把探索性結果講得像預設假說 | 失去 falsifiability |

### 顯著性判斷決策框架

```python
# 雙尾 t 檢定
from scipy import stats
t_stat, p_value = stats.ttest_ind(group_A, group_B)
```

| 情境 | 行動 | 報告方式 |
|------|------|---------|
| p < α **且** effect size 大 | 拒絕 H₀，**高信心** | "差異顯著且實質重要，d = 0.8" |
| p < α **但** effect size 小 | 拒絕 H₀，**但要警語** | "統計顯著但效應微小，d = 0.05" |
| p > α **但** effect size 中大 | 沒拒絕 H₀，**功效可能不足** | "未能拒絕 H₀，建議增加樣本（power analysis）" |
| p > α **且** effect size 小 | 接受 H₀，**無實質差異** | "資料不支持實質差異" |

**黃金法則**：永遠同時報告 p-value、effect size、信賴區間、樣本數。

### 實作方式

#### 方式一：完整報告（APA / 現代統計標準）

```python
import numpy as np
from scipy import stats

np.random.seed(42)
control = np.random.normal(100, 15, 50)
treatment = np.random.normal(105, 15, 50)

t_stat, p_val = stats.ttest_ind(control, treatment)
cohens_d = (treatment.mean() - control.mean()) / np.sqrt(
    ((len(control)-1)*control.var(ddof=1) +
     (len(treatment)-1)*treatment.var(ddof=1)) /
    (len(control)+len(treatment)-2)
)
ci_low, ci_high = stats.t.interval(0.95, len(control)+len(treatment)-2,
                                     loc=treatment.mean()-control.mean(),
                                     scale=stats.sem(np.concatenate([control, treatment])))

print(f"t({len(control)+len(treatment)-2}) = {t_stat:.2f}, p = {p_val:.4f}")
print(f"Cohen's d = {cohens_d:.3f}")
print(f"95% CI for mean diff = [{ci_low:.2f}, {ci_high:.2f}]")
```

> ❌ 錯誤：「實驗成功，p < 0.05」
> ✅ 正確：「t(98) = 2.31, p = .023, d = 0.33, 95% CI [0.62, 7.38]」

#### 方式二：Power Analysis（樣本數規劃）

```python
from statsmodels.stats.power import TTestIndPower

# 事前：在給定 effect size 下，計算需要多少樣本才能達到 80% power
analysis = TTestIndPower()
n_needed = analysis.solve_power(effect_size=0.5, alpha=0.05, power=0.80)
print(f"需 {n_needed:.0f} 樣本/組")

# 事後：給定樣本數和 effect size，計算 power
power = analysis.solve_power(effect_size=0.3, alpha=0.05, nobs1=30)
print(f"當前 power = {power:.2f}")
```

**事後 power 計算有爭議** — 嚴格派主張只能用事前 power，事後 power 不可信。

#### 方式三：多重比較校正

```python
from statsmodels.stats.multitest import multipletests
import numpy as np

# 10 個 A/B 測試（family of tests）
p_values = [0.001, 0.008, 0.039, 0.041, 0.042, 0.06, 0.12, 0.25, 0.50, 0.78]

# Bonferroni — 保守
reject_bonf, p_bonf, _, _ = multipletests(p_values, method='bonferroni')
# FDR (Benjamini-Hochberg) — 探索階段推薦
reject_fdr, p_fdr, _, _ = multipletests(p_values, method='fdr_bh')
```

| 方法 | 適用情境 | 公式 |
|------|---------|------|
| **Bonferroni** | 確認型研究、臨床試驗 | α/k |
| **Holm** | 改良 Bonferroni，較不保守 | 階梯式 |
| **Benjamini-Hochberg (FDR)** | 探索型研究、-omics、ML feature | 控制 false discovery 比例 |
| **Tukey HSD** | ANOVA 後兩兩比較 | 控制 FWER |
| **Permutation test** | 非參數、無分布假設 | 重抽 n! 次 |

#### 方式四：Bayes Factor 替代 p 值

```python
import pingouin as pg
# 計算 Bayes Factor (BF10)
result = pg.ttest(control, treatment, correction=False)
bf10 = result['BF10'].iloc[0]

# BF10 判讀
# < 1/3：支持 H₀
# 1/3 ~ 3：無決定性證據
# 3 ~ 10：中度支持 H₁
# 10 ~ 30：強支持 H₁
# > 30：極強支持 H₁
```

#### 方式五：Bootstrap 信賴區間（不假設常態）

```python
def bootstrap_diff_ci(a, b, n_boot=10000, ci=0.95):
    diffs = []
    for _ in range(n_boot):
        diffs.append(np.random.choice(a, len(a), replace=True).mean() -
                     np.random.choice(b, len(b), replace=True).mean())
    low = np.percentile(diffs, (1-ci)/2*100)
    high = np.percentile(diffs, (1+ci)/2*100)
    return low, high

# 若 CI 跨 0 → 統計上不顯著
# 若 CI 窄且偏離 0 → 強證據
```

### 在 AI / LLM 場景的應用

| 場景 | 顯著性實作 | 注意事項 |
|------|----------|---------|
| **LLM 評測** | paired bootstrap CI, paired t-test | 跑一次就報 p 是不嚴謹的（NLPRep 2023）|
| **A/B 測試** | sequential testing, mSPRT | peeking 會膨脹 type I error |
| **ML feature selection** | BH-FDR (Storey q-value) | 1000 features → 50 個假陽性 |
| **Few-shot 比較** | McNemar's test, permutation | 樣本小，常態假設失效 |
| **Reinforcement Learning** | 多次 seed + 95% CI | 不要用 single run |
| **Synthetic control** | placebo test + CI | 估計 counterfactual 不確定性 |

**特別提醒**：LLM 評測最常見的災難是「model A 比 model B 高 2 分，分數差 0.5，沒報 CI 就宣稱勝出」。**任何 LLM benchmark 報告都應該附上**：
1. 多次執行的 mean ± std
2. 95% bootstrap CI
3. paired 統計檢定
4. effect size（Cohen's d）

### 反思問題

1. 我報 p 值了嗎？**有沒有同時報 effect size 和 CI？**
2. 樣本數是否經過 power analysis？
3. 有沒有做多重比較校正？
4. 顯著性是預設的（H₁）還是事後挖到的（HARKing）？
5. 結果能 replication 嗎？是否有 pre-registration？
6. 結果對「現實使用者」重要嗎？effect size 在 practical threshold 之上嗎？
7. 我用 p > 0.05 證明「無效果」了嗎？（這是錯的）

### 經典陷阱

| 陷阱 | 解法 |
|------|------|
| p < 0.05 = 真實 | 報告 effect size + CI + 多重校正 |
| p > 0.05 = 無效 | power analysis，可能是樣本不足 |
| 大樣本萬能 | 報告 effect size，否則「顯著但無意義」|
| p-hacking | pre-register hypotheses, locked analysis plan |
| HARKing | 區分 confirmatory vs exploratory |
| 把 p 當 H 為真機率 | 改用 posterior probability 或 BF |
| 只看 p 沒看 CI | CI 包含 0 → 不顯著；CI 寬 → 證據弱 |
| 忽略常態假設 | 小樣本用 Wilcoxon, permutation test |
| 多重檢定不校正 | Bonferroni / BH-FDR |
| 假設常態但有 outlier | winsorize 或用 robust test |

### 現代統計黃金標準（從顯著性到估計的典範轉移）

> 美國統計學會（ASA）2016 與 2019 聲明明確指出：
> 1. p 值不能單獨當決定性證據
> 2. p 值不能代表假設為真的機率
> 3. 大 p 值不代表 H₀ 為真
> 4. 科學結論不能只基於 p < 0.05

**現代做法**：**New Statistics**（Cumming 2012）主張報告
- Effect size（必）
- 95% CI（必）
- 個別資料點分布（scatter, violin）
- 不只報 p，報「證據強度連續光譜」

---

**為何這個 HC 重要**：科學決策的防火牆。沒有顯著性素養，就會被「p < 0.05 萬歲」的偽科學騙；被「LLM 跑一次就勝出」的 benchmark 騙；被「大樣本讓任何差異都顯著」的自欺騙。

下次看到「實驗成功率 80%」或「A 模型勝出 B 模型」的報導，多問幾句：
> 「effect size 多大？信賴區間多寬？有沒有做多重校正？p-hacking 風險？」
