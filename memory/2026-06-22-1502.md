# Minerva HC #54：Model Types（模型類型）

## 🌿🦉 HC #54：Model Types

**定義**：模型是用來表示現實世界現象的工具——分為**心智模型（Mental）**、**數學模型（Mathematical）**、**計算模型（Computational）**三類。理解各類模型的優勢與限制，是做研究、做決策、做預測的基本功。

---

## 三類模型

### 1️⃣ 心智模型（Mental Models）
非正式的、存在於腦中的簡化表示。
- **用途**：日常推理、策略思考、溝通框架
- **例子**：SWOT 分析、波特五力、COP 模型
- **優點**：免費、快速、不需要資料
- **缺點**：容易偏差、難以精確、難以驗證

### 2️⃣ 數學模型（Mathematical Models）
用方程式描述變數之間的關係。
- **用途**：物理定律、統計推論、經濟預測
- **例子**：線性迴歸、貝氏推論、馬可夫鏈
- **優點**：可驗證、可推廣、精確
- **缺點**：依賴假設、複雜系統難建模

### 3️⃣ 計算模型（Computational Models）
用程式實作的演算法，通常用於數學模型無法解析求解的情況。
- **用途**：大資料預測、複雜模擬、黑箱最佳化
- **例子**：Random Forest、深度學習、Agent-based Model
- **優點**：可處理複雜非線性關係、規模化
- **缺點**：黑箱、依賴資料品質、資源密集

## 實作方式

### 方式一：問題類型 → 模型選擇決策樹

```
輸出類型
├─ 分類（Categorical）
│   ├─ 簡單決策邊界 → Logistic Regression / SVM
│   └─ 複雜決策邊界 → Random Forest / Gradient Boosting / Neural Net
│
├─ 迴歸（Continuous）
│   ├─ 需要解釋 → Linear / Polynomial Regression
│   └─ 需要預測精度 → XGBoost / Neural Net / Gaussian Process
│
├─ 時間序列
│   ├─ 傳統統計 → ARIMA / Prophet
│   └─ 深度學習 → LSTM / Transformer
│
└─ 聚類（無標籪）
    ├─ 距離基礎 → K-Means / DBSCAN
    └─ 分布基礎 → GMM（高斯混合模型）
```

### 方式二：No-Free-Lunch 定理實務應用

> **沒有任何模型在所有問題上都最優。**

| 模型類型 | 優點 | 缺點 | 適用場景 |
|----------|------|------|----------|
| Linear Regression | 可解釋、快速 | 只能捕捉線性關係 | 解釋性優先、資料線性 |
| Random Forest | 魯棒、不需特徵工程 | 黑箱、記憶體密集 | 表格資料、雜訊多 |
| Neural Net | 捕捉複雜模式 | 需要大量資料、難解釋 | 影像、文字、序列 |
| Gaussian Process | 不確定性估計 | O(n³) 複雜度 | 小資料、科學預測 |
| K-Means | 快速、易實作 | 需預設 k、對初始值敏感 | 大型無標籪資料 |

### 方式三：模型驗證框架（Python）

```python
from sklearn.model_selection import cross_val_score, StratifiedKFold

# 分層 K-Fold（分類問題首選）
scores = cross_val_score(model, X, y, 
                          cv=StratifiedKFold(n_splits=5))

# 小資料集 → 留一法交叉驗證
from sklearn.model_selection import LeaveOneOut
scores = cross_val_score(model, X, y, cv=LeaveOneOut())
```
