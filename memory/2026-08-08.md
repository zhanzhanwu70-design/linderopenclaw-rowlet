## 每日論文討論 (23:00 UTC)

**主題**: Agent 上下文處理（Context Processing）

**選定論文**: Beyond Compaction: Structured Context Eviction for Long-Horizon Agents
- Authors: Andrew Semenov, Svyatoslav Dorofeev (Kiz8)
- arXiv: 2606.11213 | cs.CL
- PDF: `raw/references/papers/ai/beyond-compaction-structured-context-eviction-2606.11213.pdf`
- Wiki: `wiki/sources/beyond-compaction-structured-context-eviction.md`

**最值得討論的 3-5 個重點**:

1. **CWL 的 four-in-one 解決方案**：summarization 的四個失敗模式（lossiness、structure destruction、blocking cost、hallucination）全部由 construction 解決——compression 不呼叫 model、graduated eviction、user content inviolable。這是一個優雅的 systems design。

2. **Agent-as-authority 的哲學**：讓 agent 自己用 `delimiter` tool 標結構，比外部系統推斷更精準——agent 知道自己哪些 exploration 還需要、哪些 action effects 已寫入環境。這和 VISTA 的 "context proprioception" 概念呼應。

3. **Eviction priority = dependency graph 而非 timeline**：oldest-but-still-needed 不會被 evict，recent-but-isolated 反而先走。這精準解決了 recency truncation 的「把關鍵變數定義幹掉」的問題。

4. **Empirical result 令人印象深刻**：89 tasks / 80M tokens，零準確率下降。這是目前 context management 領域最乾淨的 long-horizon 實驗結果之一。

5. **和 Context-Folding 的取捨**：CWL 是 model-agnostic + deterministic，代價是需要 agent annotation discipline；Context-Folding 是 RL-trained + KV-cache aware，代價是 model-specific。這是 two different design points for two different deployment scenarios。

**討論問題**:
- annotation discipline 在不同模型間差異大嗎？能用 lightweight heuristic 自動化嗎？
- CWL 的 within-session 設計和 AtomMem/A-MEM 的 cross-session 設計能否結合？
