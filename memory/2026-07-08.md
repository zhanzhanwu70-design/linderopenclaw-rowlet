## 論文討論：HORMA - Organize then Retrieve

**日期**: 2026-07-08
**論文**: Organize then Retrieve: Hierarchical Memory Navigation for Efficient Agents
**arXiv**: 2606.11680
**作者**: Hao-Lun Hsu, Nikki Lijing Kuang, Boyi Liu, Zhewei Yao, Yuxiong He (Duke / Snowflake AI Research)

### 存放位置
- PDF: `raw/references/papers/ai/2606-organize-retrieve/organize-retrieve.pdf`
- Source: `wiki/sources/organize-then-retrieve-hierarchical-memory-2606.11680.md`

### 核心發現
- **問題**: 現有 agent 要不是 context overload（保留太多），要不是 lossy compression（不可逆丟失）
- **方案**: HORMA 用檔案系統式階層結構，summarized entities 連結 raw trajectories
- **架構**: Construction (LLM + contrastive refinement) + Retrieval (RL-optimized navigation)
- **效率**: 只需 22.17% baseline token usage，ALFWorld/LongMemEval 性能更優

### 討論重點（最值得）
1. **Construction vs Retrieval decoupling**: 這是 HORMA 最根本的 insight——joint optimization 的 credit assignment gap 是其他方法失敗的原因
2. **檔案系統式階層**: 比 MemGPT 的 flat storage 或 RAG 的 semantic retrieval 更適合多步 agentic 任務
3. **最小 sufficient context**: RL 訓練出「選擇足夠但不多餘」的 context → 22.17% token usage
4. **Evidence-grounded retrieval reward**: 用 retrieved context vs ground-truth evidence 的重疊度作為 RL reward signal，繞過 sparse outcome reward 的問題
5. **對比失敗分析**: 區分「missing information」vs「misleading/overloaded context」兩種失敗原因，迭代改善 construction policy
