## 🌿🦉 Minerva HC #20：Logical Fallacies（邏輯謬誤）

### 定義

**Logical Fallacy（邏輯謬誤）** — 推理過程中**形式錯誤**或**前提可疑**的論證模式，使結論**看似合理但實際上未被支持**。

核心三類：
1. **形式謬誤（Formal）** — 推論形式無效（#19 演繹的反面）
2. **內容謬誤（Informal / Content）** — 推論有效但前提可疑、依賴錯誤假設
3. **語境謬誤（Pragmatic）** — 利用語言模糊、情緒、權威等「修辭技巧」誤導

> **一句話**：謬誤 = 「聽起來對，邏輯不對」或「邏輯對，前提毒」。

> 與 #19 Deductions 的關係：**#19 教你建構有效論證，#20 教你拆解無效論證**。兩者互為表裡。

---

### 為什麼這個 HC 重要？

| 場景 | 沒有謬誤素養的災難 |
|------|------------------|
| **政治宣傳 / 媒體** | 被滑坡、稻草人、訴諸情感說服，做出錯誤投票 |
| **商業決策** | 被 sunk cost、appeal to novelty、bandwagon 誤導投資 |
| **科學論文** | 沒識別 p-hacking、HARKing、publication bias |
| **AI 開發** | 沒識別 LLM 的 sycophancy、false dichotomy、confirmation bias |
| **日常生活** | 被 guilt-tripping、moving the goalpost、whataboutism 操控 |
| **法律論證** | 沒識別 hearsay、leading question、loaded question |

**歷史教訓**：
- 20 世紀大屠杀：部分由「**群體謬誤**（groupthink）」和「**訴諸傳統**」促成
- 金融危機：sunk cost fallacy + appeal to authority + recency bias
- Replication crisis：publication bias + p-hacking + HARKing

> **心理學實證**：人类平均每天被 5–10 個謬誤影響，**99% 的謬誤未被識別**（Kahneman, 2011; Pennycook & Rand, 2019）。

### 謬誤分類架構

```
謬誤
├── 形式謬誤（Formal Fallacies）        # 形式無效
│   ├── 演繹謬誤（Deductive）            # 結論不必然從前提出
│   └── 歸納謬誤（Inductive）            # 證據不充分
│
├── 內容謬誤（Informal / Content）       # 推論形式 OK，前提可疑
│   ├── 預設謬誤（Presumption）          # 預設了未證明的東西
│   ├── 相關性謬誤（Relevance）          # 前提和結論無關
│   └── 不充分謬誤（Insufficiency）      # 證據太少
│
└── 語境/修辭謬誤（Pragmatic）          # 利用語言/情緒/語境
    ├── 語言模糊謬誤                     # Equivocation, amphiboly
    ├── 結構性謬誤                       # 提問方式影響答案
    └── 情感/社會謬誤                     # 恐嚇、同情、從眾
```

### 經典謬誤速查表（依結構分類）

#### A. 演繹謬誤（與 #19 對應 — 形式無效）

| 謬誤 | 形式 | 反例 | 為何錯 |
|------|------|------|--------|
| **肯定後件（Affirming the Consequent）** | P→Q, Q ⊢ P | 下雨→地濕，地濕，∴ 下雨 | 灑水器也會讓地濕 |
| **否定前件（Denying the Antecedent）** | P→Q, ¬P ⊢ ¬Q | 下雨→地濕，沒下雨，∴ 地不濕 | 灑水器讓地濕 |
| **Undistributed Middle** | All A are C, All B are C ⊢ All A are B | 貓是哺乳動物，狗是哺乳動物，∴ 貓是狗 | 中項沒 distribute |
| **Illicit Major** | All A are B, No C are A ⊢ No C are B | — | 大項 distribute 錯 |
| **Illicit Minor** | All M are P, No S are M ⊢ No S are P | — | 小項 distribute 錯 |
| **False Dilemma / False Dichotomy** | 只有 P 或 Q 兩個選項 | 要麼支持我，要麼反對我 | 忽略第三選項 |
| **Equivocation** | 同一詞不同意思 | 「法律是法律」 | 詞義滑動 |

#### B. 歸納謬誤（與 #21 對應 — 證據不充分）

| 謬誤 | 描述 | 例子 |
|------|------|------|
| **Hasty Generalization** | 樣本太少就概括 | 遇過 3 個粗魯的紐約人，∴ 紐約人都粗魯 |
| **Anecdotal Fallacy** | 用個案代替統計 | 我爺爺抽煙活到 100，∴ 抽煙無害 |
| **Sampling Bias** | 樣本不具代表性 | 電話民調只打有線電話（老年人多）|
| **Survivorship Bias** | 只看存活者 | 看成功企業家特質，忽略倒閉的 |
| **Base Rate Fallacy** | 忽略基率 | 陽性 = 99% 機率得病（忽略病罕見）|
| **Conjunction Fallacy** | P×Q 比 P 更可能 | 林達 34 歲，圖書館員，活躍女性主義，比「圖書館員」更可能？（否）|
| **Gambler's Fallacy** | 獨立事件有關 | 連開 5 次大，下次更可能小（否）|
| **Regression Fallacy** | 把回歸均值當因果 | 罵學生成績上升，罵有效（其實是回歸）|
| **Ecological Fallacy** | 群體結論套個人 | A 州平均智商高，∴ A 州某人智商高 |
| **Fallacy of Composition** | 個體性質推整體 | 每人站著看球賽看得更清楚，∴ 全場站著看得更清楚 |
| **Fallacy of Division** | 整體性質推個體 | 這支球隊很強，∴ 隊員都很強 |

#### C. 相關性謬誤（Red Herring — 轉移焦點）

| 謬誤 | 描述 | 反駁 |
|------|------|------|
| **Ad Hominem（人身攻擊）** | 攻擊人格/動機而非論點 | 重新聚焦論點本身 |
| **Tu Quoque（你也一樣）** | 你也這樣，憑什麼說我 | 論點獨立於言者行為 |
| **Genetic Fallacy** | 因來源否定論點 | 真理與來源無必然關係 |
| **Red Herring** | 引入不相關話題轉移焦點 | 拉回主題 |
| **Strawman（稻草人）** | 扭曲對方論點再攻擊 | 引用對方原話 |
| **Appeal to Emotion（訴諸情感）** | 用恐懼/同情代替論據 | 要求實質理由 |
| **Appeal to Authority** | 「專家說」但無理由 | 要求專家論據 |
| **Appeal to Nature** | 「天然 = 好」 | 砒霜也是天然的 |
| **Appeal to Tradition** | 「一直這樣所以應繼續」 | 過去對不代表現在對 |
| **Appeal to Novelty** | 「新的 = 更好的」 | 新的可能更糟 |
| **Appeal to Popularity（Bandwagon）** | 「大家都這樣」 | 多數不等於正確 |
| **Appeal to Ignorance** | 沒證明假 = 真 | 沒證明有外星人 ≠ 沒有 |
| **Moving the Goalposts** | 要求越來越強的證據 | 鎖定原始標準 |
| **Whataboutism** | A 有問題所以 B 沒問題 | 每個議題獨立評估 |
| **Two Wrongs Make a Right** | 你也錯了所以我對 | 雙方對錯獨立 |

#### D. 預設謬誤（Loaded Question / Begging the Question）

| 謬誤 | 描述 | 例子 |
|------|------|------|
| **Begging the Question（循環論證）** | 結論藏在前題 | 「聖經是神的話因為神說的話不會錯」|
| **Loaded Question** | 問題暗含未證假設 | 「你還在打老婆嗎？」|
| **Complex Question** | 多個問題合成一個 | 「為什麼你對我撒謊？」|
| **Leading Question** | 引導特定答案 | 「你不覺得 X 很棒嗎？」|
| **False Cause（Cum Hoc）** | 相關 = 因果 | 冰店銷售和溺水死亡正相關，∴ 冰店造成溺水（其實都是夏天造成）|
| **Post Hoc** | 之後 = 因此 | 換髮型後中樂透，∴ 髮型帶來好運 |
| **Slippery Slope（滑坡）** | A→B→Z 必然發生 | 允許同性婚姻，∴ 人類會和動物結婚（無依據跳躍）|
| **No True Scotsman** | 不符預期就排除 | 「沒有真正的蘇格蘭人會這樣做」|
| **Special Pleading** | 為自己開特例 | 我的理論不對，是因為「這次情況特殊」|

#### E. 統計/科學謬誤（科研與 AI 必備）

| 謬誤 | 描述 | 識別方法 |
|------|------|---------|
| **P-hacking** | 反覆檢定直到 p < 0.05 | 看樣本數和檢定次數 |
| **HARKing** | 事後講成事前假設 | 區分 confirmatory / exploratory |
| **Publication Bias** | 只發顯著結果 | 看 funnel plot, registered reports |
| **Garden of Forking Paths** | 沒預設的分析路徑 | pre-registration |
| **Texas Sharpshooter** | 選好 cluster 再畫框 | 看資料採集時間順序 |
| **Cherry Picking** | 只挑支持證據 | 要求完整資料 |
| **Simpson's Paradox** | 群體趨勢在子組反轉 | 看分層資料 |
| **McNamara Fallacy** | 只看可量化指標 | 加上質化觀察 |
| **Law of Small Numbers** | 小樣本視為大樣本 | 看 n 大小 |

#### F. 結構性/語境謬誤

| 謬誤 | 描述 | 例子 |
|------|------|------|

| **Naturalistic Fallacy** | 實然推應然 | 「人天生自私」∴ 「自私是對的」|

| **Definitional Retreat** | 反駁失敗就改定義 | — |

### 謬誤偵測演算法（核心實作）

```python
class FallacyDetector:
    def __init__(self):
        self.patterns = {
            "ad_hominem": ["他/她這種人", "你自己也不是", "人品有問題"],
            "strawman": ["所以你是說", "你的意思是"],
            "false_cause": ["因為...所以", "之後...因此"],
            "appeal_to_authority": ["專家說", "科學已經證明"],
            "false_dilemma": ["要麼...要麼", "只有兩種可能"],
            "slippery_slope": ["接下來就會", "最後一定會"],
            "begging": ["因為...所以...（同義反覆）"],
            "loaded_question": ["你為什麼還在", "你是不是"],
            "appeal_to_emotion": ["想想孩子", "如果你愛"],
            "hasty_generalization": ["我認識的人", "我朋友"],
        }
    
    def detect(self, argument: str) -> list[dict]:
        detected = []
        for fallacy, keywords in self.patterns.items():
            for kw in keywords:
                if kw in argument:
                    detected.append({
                        "fallacy": fallacy,
                        "trigger": kw,
                        "confidence": 0.6  # keyword-based is weak signal
                    })
        return detected
    
    def explain(self, fallacy: str) -> str:
        return self.explanations.get(fallacy, "未識別")
```

> **警告**：keyword-based 是弱信號，**必須結合 LLM semantic + argument structure parsing** 才實用。

def detect_fallacy_with_llm(argument: str, model) -> dict:

### 在 AI / LLM 場景的應用

| 場景 | 謬誤風險 | 防禦策略 |
|------|---------|---------|
| **LLM Sycophancy** | LLM 同意使用者錯誤前提 | 強制 LLM 反方論證 + 列出假設 |
| **LLM False Confidence** | LLM 給 0/1 答案而非機率 | 設定 temperature + uncertainty expression |
| **LLM 推理謬誤** | LLM 生成 strawman / ad hominem 攻擊對手 | Constitutional AI + fallacy-aware prompting |
| **AI 評測** | Benchmark overfitting（Texas sharpshooter）| 預註冊 + 留置測試集 |
| **AI Alignment** | 優化到 proxy 而非真目標（Goodhart's Law）| multi-metric + causal validity check |
| **生成式搜尋** | Cherry-picking 來源 | 強制 N-source 平衡 |
| **RAG Hallucination** | 拼接不相關片段製造偽結論 | NLI 一致性檢查 |
| **推薦系統** | Survivorship bias | counterfactual evaluation |
| **AI 倫理** | 將相關當因果（公平性謬誤）| causal inference + interventional data |

**特別提醒 — LLM 特有的「偽邏輯」謬誤**：

| LLM 謬誤 | 描述 | 解法 |
|---------|------|------|
| **Confabulated Syllogism** | 構造聽起來合理的三段論但前提假 | 預先驗證前提 |
| **False Balance** | 給極端和主流同等時間 | weighted by evidence quality |
| **Anthropomorphic Projection** | 「它想要」「它相信」| 區分功能 vs 意向 |
| **Appeal to LLM Itself** | 「身為 AI 我認為」| 要求論據 |
| **Sycophantic Reframing** | 同意但換個說法 | 要求直接說「你錯了」當實際錯時 |
| **Hedge Inflation** | 處處加 disclaimer 逃避判斷 | 區分 hedge / 模糊 |

### 與 #21 Induction 的關鍵關係

#21 Induction 的失敗模式幾乎都是 #20 的歸納謬誤：
- Hasty Generalization = 樣本不足的歸納
- Survivorship Bias = 樣本選擇偏差的歸納
- Post Hoc = 因果歸納錯
- False Cause = 相關性歸納錯

學 #20 = 學 #21 的失敗清單。

### 與 #24 Confirmation Bias 的關係

**Confirmation Bias 是謬誤的**心理機制**，#20 是謬誤的**形式清單**。**沒有 #24，學了 #20 也會繼續犯。

例如你已學會識別 Strawman 謬誤，但你有 Confirmation Bias 傾向，你仍會：
- 只記得對手用 strawman 的例子
- 忘記自己用 strawman 的時候
- 把對手的弱化視為「合理」

> **結論**：學 #20 同時必須學 #24/#23/#25/#26 等 metacognition HC。

6. 我在 LLM 對話中：有沒有接受 sycophancy？**有沒有要求反方論證**？
7. 對手的論證讓我情緒激動嗎？**如果是，更可能我在用 appeal to emotion**？
8. 我的「常識」是不是 base rate fallacy？**查基率**。

### 經典陷阱

| 陷阱 | 解法 |
|------|------|
| 把謬誤當「修辭技巧」中性看待 | 謬誤會誤導決策，**必須識別並反駁** |
| 只識別別人的謬誤 | **對自己更嚴格**（bias blind spot）|
| 看到關鍵字就說是謬誤 | 必須**結構性檢查**，keyword 不夠 |
| 認為「沒犯謬誤 = 論證對」 | Validity ≠ Soundness（#19/#20 結合）|
| 把修辭問題當邏輯謬誤 | 修辭 ≠ 謬誤（例：誇飾是修辭，fallacy 是邏輯）|
| 認為謬誤清單背下來就會用 | 必須 **deliberate practice**，寫作時自我檢查 |
| 認為 LLM 永遠不犯謬誤 | LLM **特別會犯偽邏輯**（confabulated syllogism）|
| 把「我不同意」當「對方謬誤」 | 不同意 ≠ 謬誤，可能是 premise disagreement |

### 反駁的建設性方式（謬誤識別的目的不是吵架）

**三明治法**：
1. **肯定合理部分**：「你說的 X 有道理，因為...」
2. **指出問題**：「不過我注意到論證中可能是 Y 謬誤，因為...」
3. **共同探索**：「也許可以這樣重新框架...」

**例子**（對「年輕人都不努力」的反駁）：
- ❌ Ad Hominem：「你老了不懂」
- ❌ Strawman：「所以你主張讓年輕人挨餓？」
- ✅ 結構性：「這個論證包含 hasty generalization（樣本是誰？）。讓我們看 [具體資料]。」

**Steve Jobs 的建議**：
> "Don't be a jerk. You can disagree without being disagreeable."

### 謬誤素養的極限（誠實補充）

| 限制 | 說明 |
|------|------|
| **修辭有時合理** | 演講、廣告不可能全形式化 |
| **文化差異** | 某些修辭在 A 文化是謬誤，B 文化是禮貌 |
| **灰色地帶** | Slippery slope 預測未來有時是合理的（如氣候變遷）|
| **無法窮舉** | 新謬誤不斷出現（deepfake, AI-specific）|
| **執行成本** | 每個論證都檢查 → 認知過載 |
| **對話崩壞** | 對方覺得被「糾謬誤」會防衛反彈 |

> **平衡**：在**重要決策**（投票、投資、倫理）嚴格檢查；在**日常對話**抓大放小。
