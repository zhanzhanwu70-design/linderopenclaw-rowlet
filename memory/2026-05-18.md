### uutagent SVG → PNG rendering investigation

**Problem**: User wanted to convert uutagent presentation SVGs to PNG. Three SVGs:
- 01-uutagent-overview.svg
- 02-uutagent-4phases.svg
- 03-uutagent-verify-learning.svg

**Attempted solutions (all failed)**:

1. **resvg-js** (available in workspace npm)
   - CJK text renders as outline/stroke only - extremely faint pixels, not filled glyphs
   - English text with system fonts (Arial, Segoe UI) - also renders as outline, no filled glyphs
   - Root cause: resvg parses font but renders text as stroke instead of fill
   - Confirmed: Noto Sans CJK TC, Segoe UI, Arial all trigger outline mode in resvg
   - No font files found in environment - resvg can't find/install fonts

2. **node-canvas** - not available in this environment

3. **PIL/Cairosvg/svglib** - none available

4. **playwright + chrome-headless-shell**
   - Installed playwright via npx
   - Downloaded chromium (113 MiB)
   - Browser launches but immediately crashes/closes
   - Chrome-headless-shell missing libglib dependencies, no root to install

5. **html-to-image package** - not available

**Conclusion**: This environment has no working path to render text in SVG to PNG. resvg is fundamentally limited for text rendering (outline vs fill issue). No browser, no root, no PIL, no node-canvas.
