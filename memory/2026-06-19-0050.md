## 🌿🦉 Minerva HC #17：Bayesian Statistics（貝氏統計）

### 定義

**貝氏統計** — 把「我相信什麼」和「我看到什麼」分開，然後用一條公式把它們組合成「看到這些證據之後我應該相信什麼」。它是**更新信念的數學**，不是「另一種統計檢定」。

> 核心公式：$P(H \mid E) = \dfrac{P(E \mid H) \cdot P(H)}{P(E)}$

頻率派問：「如果虛無假設為真，我看到這種資料的機率是多少？」
貝氏派問：「看到這種資料之後，每個假設為真的機率是多少？」

---

### 為什麼需要貝氏統計？

頻率派 p 值有四個著名盲點：

1. **不能直接說「H 為真的機率是 X%」** — p 值是條件在 H 為真的時候，反過來無效。
2. **小樣本時 p 值不可信** — 資料不夠時 p 值劇烈擺動，貝氏方法天生融合先驗。
3. **不能表達「我原本就相信的事」** — 醫生看到症狀前已有先驗（這個病很罕見），頻率派完全忽略。
4. **不能直接做預測分佈** — 貝氏方法天然給出整個後驗分佈。

**一句話**：頻率派回答「資料多極端」，貝氏派回答「我相信什麼」。

---

### 核心觀念速查

| 概念 | 公式符號 | 意思 |
|------|---------|------|
| **Prior** | $P(H)$ | 看到證據前你相信 H 的程度 |
| **Likelihood** | $P(E \mid H)$ | H 為真下看到 E 的機率 |
| **Evidence** | $P(E)$ | E 在所有假設下的總機率（正規化常數）|
| **Posterior** | $P(H \mid E)$ | 看到 E 之後你對 H 的更新信念 |
| **Likelihood ratio** | $\frac{P(E \mid H_1)}{P(E \mid H_0)}$ | 證據對兩個假設的相對支持度 |
| **Credible interval** | — | 「H 有 95% 機率在這區間」（**直接是機率**）|
| **Posterior predictive** | — | 整合不確定性後對新資料的預測分佈 |

### 實作方式

#### 方式一：手算經典案例（醫學檢測）

```python
def medical_test_posterior(prevalence, sensitivity, false_positive):
    p_pos = sensitivity*prevalence + false_positive*(1-prevalence)
    return (sensitivity * prevalence) / p_pos

# 萬分之一盛行的病，敏感度 99%、特異度 99%
result = medical_test_posterior(0.0001, 0.99, 0.01)
# ≈ 0.0098 — 不到 1%！基率謬誤
```

#### 方式二：PyMC — A/B 測試

```python
import pymc as pm
import arviz as az

with pm.Model() as ab_test:
    p_A = pm.Beta("p_A", 1, 1)
    p_B = pm.Beta("p_B", 1, 1)
    pm.Binomial("obs_A", n=200, p=p_A, observed=30)
    pm.Binomial("obs_B", n=200, p=p_B, observed=45)
    pm.Deterministic("prob_B_better", pm.math.gt(p_B, p_A))
    trace = pm.sample(4000, tune=2000, target_accept=0.95)

print(f"P(B > A) = {trace.posterior['prob_B_better'].mean():.3f}")
az.plot_posterior(trace, var_names=["diff"], ref_val=0)
```

#### 方式四：共軛先驗速查

| 似然 | 先驗 | 後驗 | 場景 |
|------|------|------|------|
| Bernoulli | Beta | Beta | A/B 測試、CTR |
| Binomial | Beta | Beta | 轉換率 |
| Poisson | Gamma | Gamma | 事件率 |
| Normal (mean) | Normal | Normal | 量測平均 |
| Multinomial | Dirichlet | Dirichlet | 主題模型 |

#### 方式五：MCMC / VI 演算法選擇

| 演算法 | 適用 | 速度 |
|--------|------|------|
| Metropolis-Hastings | 簡單通用 | 慢 |
| Gibbs Sampling | 條件後驗易求 | 中 |
| HMC / NUTS | 連續參數（PyMC 預設） | 快 |
| Variational Inference | 大模型、線上 | 極快 |
| emcee (ensemble) | 多模後驗 | 中 |

### 在 AI / LLM 場景的應用

| 場景 | 貝氏做法 | 為何貝氏更優 |
|------|---------|------------|
| 模型校準 | Dirichlet 先驗 + temperature scaling | 真實不確定性 |
| A/B 平台 | Beta-Binomial 共軛逐步更新 | 提早停止不膨脹偽陽性 |
| Few-shot / ICL | Prior over task 引導 prompt | 融合隱式先驗 + 範例 |
| 主動學習 | 選後驗不確定性最高樣本 | 比隨機少 50%+ 標註 |
| RAG relevance | BM25/dense 當 likelihood + 文件 prior | 可解釋排序 |

**特別提醒**：LLM self-reported confidence 嚴重過度自信。**真正校準需要 temperature scaling 或 ensemble**。

### 反思問題

1. 先驗從哪來？是否強加領域知識？
2. 似然假設合理嗎？（常態、i.i.d.、無系統誤差）
3. MCMC 收斂嗎？（R̂ < 1.01、ESS、trace plot）
4. 後驗是不是多模的？平均值會誤導。
5. Posterior predictive check：模擬 vs 實際差多少？
6. Prior → uniform 時後驗趨近 MLE？（應該要）
7. Bayes Factor 量化「證據有多強」？

### 經典陷阱

| 陷阱 | 解法 |
|------|------|
| 先驗過強 | 用 weakly informative prior |
| 先驗過弱 | 退化成 MLE，沒做貝氏的理由 |
| Likelihood 寫錯 | Prior predictive check |
| 忘了 marginal | 共軛先驗或 MCMC |
| MCMC 未收斂 | R̂、ESS、trace plot |
| 用 MAP 當 point estimate | 報 posterior median + 95% CrI |
| 認為貝氏 = 主觀 | 「先驗是透明假設，p 值是隱形假設」 |
