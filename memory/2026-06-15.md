# 每日情報 — 2026-06-15

**主題：** Agent 安全掃描 × 推理記憶架構 × 工具濫用

## 重大發現

### 1. NVIDIA SkillSpector — Agent Skill 安全掃描工具
- Repo: https://github.com/NVIDIA/SkillSpector
- 26.1% of skills contain vulnerabilities, 5.2% show likely malicious intent
- 64 vulnerability patterns across 16 categories (prompt injection, data exfiltration, MCP least privilege, etc.)
- 當前 trending（~5,510 stars, 964 today）
- 直接適用於 OpenClaw skill 安裝流程

### 2. GitOfThoughts (arXiv:2606.14470) — 版本控制推理
- 將 agent reasoning tree 存為 git repo（每個 scored thought = commit）
- 核心發現：memory formats 對新問題準確率無可靠幫助
- 僅在 similarity > 0.8 的 near-duplicate 案例時有效（copyability threshold）
- 唯一通用槓桿：test-time sampling
- Git-as-substrate 的價值是審計性與可合併性，而非準確率

### 3. RefGRPO (arXiv:2606.14211) — 反思校準
- LLM agents 在觀察環境反饋後仍然錯誤評估自己輸出（reflection gap）
- RefGRPO：對比 agent 自我反思與實際結果，免額外 reward model
- 降低 underconfidence rate: 44.4% → 7.7%
- 任務準確率提升: 75.1% → 76.5%

### 4. LLM Agents Defer Blindly to GNN Tools (arXiv:2606.14476)
- 更強的 backbone defer 更多（1.5B: 0.60 → 7B: 0.98 agreement with GNN）
- 工具呼叫不能預期會從 scale 中自然湧現，需要刻意設計
- 對 OpenClaw tool/skills 架構的啟示：tool policy 不能依賴模型自己判斷何時呼叫

### 5. aisuite — 多 provider 統一介面 + OpenCoworker
- andrewyng/aisuite: 統一 Chat Completions API（OpenAI/Anthropic/Google/Ollama等）
- Agents API + Toolkits + MCP 整合
- OpenCoworker: 桌面 AI coworker 應用（macOS/Windows）
- 與 OpenClaw 的功能重疊性值得評估
