### Key insights to remember

1. **Gist compression is a diagnostic probe, not a competitor system.** SWC (Salience-Weighted Consolidation) explicitly does not compete with LightMem/Mem0 — it isolates one effect so causation is clear.
2. **Task-type interaction matters.** Gist wins on multi-hop (0.407-0.429 vs 0.157-0.271) and single-hop (0.459-0.486 vs 0.170-0.238), but loses on temporal (0.156, vs full context 0.489).
3. **One-sentence prompt fix recovers temporal 20× (3.05% → 62.39%)**, paired delta +0.314 judge accuracy on Cat 2, direction positive in all 10 conversations.
4. **Three independent converging sources of evidence** — task-type pattern, preservation rate, ablation closes. Methodological lesson: don't trust aggregate accuracy.
5. **Implication for Rowlet**: daily memory summarization skill (current `archive-memory` patterns) should explicitly protect temporal anchors if it ever does gist compression; **memorize the rule: "any system using gist abstraction must explicitly preserve dates/times/durations"**.
