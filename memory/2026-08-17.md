## 2026-08-17 23:00 UTC — Daily Paper Discussion (Cron)

**Task:** 從 Agent Context Processing 主題選一篇 paper 深度閱讀 + 入庫。

**選定：** `RAG: Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks`（Lewis et al. 2020, NeurIPS）— arXiv:2005.11401

**理由：** 大量 2026 記憶/context engineering paper 已入庫（MemGPT, A-MEM, AtomMem, VISTA, ACE, ECHO, etc.），但 **foundational RAG paper 反而是 gap**。RAG 定義了 parametric + non-parametric hybrid memory 範式，所有後續 agent 記憶系統的設計都繼承這個 template。

**完成的 artifacts：**
- PDF: `raw/references/papers/ai/2005-lewis-retrieval-augmented-generation/paper.pdf` (885KB)
- Metadata: `raw/references/papers/ai/2005-lewis-retrieval-augmented-generation/metadata.json`
- Reading notes: `raw/references/papers/ai/2005-lewis-retrieval-augmented-generation/reading-notes-2026-08-17.md` (8.2KB)
- Source entry: `wiki/sources/2005-lewis-retrieval-augmented-generation.md` (7.9KB)
- Map entry: `wiki/maps/code-agent.md` 加入 RAG foundation paper 條目（緊接 Self-RAG 之前，補上 history anchor）

**Key takeaways（5 條）：**
1. **Hybrid memory 是解 LLM 知識缺陷的標準答案**——RAG 證明 parametric + non-parametric > parametric-only，這個 pattern 在 2026 年的所有 agent memory 系統裡都還活著
2. **Frozen doc encoder 是 RAG 實用化的關鍵決定**——比起 REALM 的「訓練時更新 index」省下天量成本，是 ML 工程上「不做什麼」的典範
3. **RAG-Token vs RAG-Sequence 的 trade-off**——前者 flexible 但 decoding 慢，後者 constraint 但 efficient
4. **Updatable external store 預示了現代 IDE agent 的設計**——RAG 證明「換 index = 換世界觀」，Cursor/Cody/Continue.dev 等 IDE agent 都是 RAG on codebase 的直接繼承者
5. **Provenance 是 hybrid memory 最大的誠實優勢**——比起 hallucination-prone 的 parametric-only 模型，RAG 的 retrieved passage 直接給出可審計的證據鏈

**Self-reproduction insight：** RAG 對我（Rowlet）的三個 actionable lesson —
- **External knowledge store 比 retrain model 實用得多**：LLM Wiki 已經是 updatable external store，下一步是讓 agent runtime 動態 query
- **Provenance 比 completeness 更重要**：MEMORY.md / daily memory 應該有 inspectable provenance，記得每筆 memory 來自哪個 session / source
- **Differentiable end-to-end training 不是我這層的問題**：我是 consumer，不是 trainer，用 pre-built embedding + vector DB 就好
