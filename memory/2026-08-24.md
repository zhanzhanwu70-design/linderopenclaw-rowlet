## Key findings (3-5)
1. **Textual gradient on prompts > RL on agent weights** — model-agnostic, ~$2 optimization cost per benchmark, works for any API-only LLM
2. **Equalizer finding** — small LMs benefit MORE from compression (Qwen3-14B +32.4% on AppWorld, +45.6% on 8-QA)
3. **UT vs UTCO is a deployable knob** — verbose env → UTCO, fact-critical → UT
4. **Distillation is mandatory** — Table 4 shows compressor saves tokens but adds latency; only viable with distilled small LM
5. **Compression as filtering** — on 8-QA, ACON's compressed context BEATS no-compression baseline on EM/F1
