## Whisper pipeline 損壞後的 workaround

- `~/.openclaw/local/bin/whispercpp-transcribe` 已不存在，整個 `~/.openclaw/local/` 消失
- `faster-whisper` (Python package) 用 `pip install faster-whisper` 後可立刻頂上
  - 跑：python3 -c "from faster_whisper import WhisperModel; m = WhisperModel('small', device='cpu', compute_type='int8'); ..."
  - 注意：長音頻跑會被 SIGKILL，用 `nohup ... & disown` 脫離 exec session 才能跑完
- Graphify 也壞了：`.venv-graphify/` 是 Windows venv（Python 3.13 from WindowsApps），Linux 跑不了
  - 暫時跳過 graphify extract，log.md 已手動補上
