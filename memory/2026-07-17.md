### 核心問題
Multi-session RL 訓練中，memory 讓環境非穩態——不同 rollouts 寫入不同記憶後，GRPO 仍把它們放同一組 normalize，導致 credit assignment 失效。

### 三大貢獻
1. **LoGo-GRPO**：Local + Global GRPO，前者在同一 memory state 公平比較不同 action，後者保留長視野端到端學習
2. **Shared-parameter Extractor–Manager**：一個 LLM backbone + role-specific prompts，同時優化 memory formation 和 evolution
3. **Progressive curriculum**：8→16→32 sessions，先短後長穩定訓練

### 與現有工作關係
- 同樣 credit assignment → ECHO（selective reconstruction + source pointers）
- 同樣 atomic memory → AtomMem（但 R2 貢獻在 credit assignment）
- 互補 → VISTA（VISTA 解決 proprioception，R2 解決 RL training）
