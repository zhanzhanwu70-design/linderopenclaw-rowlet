## 🌿🦉 Minerva HC #22：Prediction（預測）

### 定義

**Prediction（預測）** — 基於**現有證據 + 模型**推斷**未發生事件**的數值、方向或時機。是 #21 Induction 從「描述過去」升級到「指向未來」的應用層。

核心三特徵：
1. **方向**：已知 → 未知（known → unknown）
2. **時間錨定**：結論必須有**時間點**（明天 / 2027 / 十年內）
3. **不對稱錯誤**：Type I 誤報成本 ≠ Type II 漏報成本，預測的**成本函數**是核心

> **一句話**：預測是「用過去的歸納模型 + 對未來的承擔」，**沒有時間錨定的「預測」是猜測**。

形式符號：$P(Y_{t+n} | X_t, M, \theta)$ — 給定資料 $X_t$、模型 $M$、參數 $\theta$，對 $n$ 步後的 $Y$ 給出分布。

**與 #21 Induction 的差異**：

| 維度 | #21 Induction | #22 Prediction |
|------|---------------|----------------|
| 對象 | 過去 / 當前樣本 | 未來事件 |
| 風險 | 過度概括 | 黑天鵝 / 分布漂移 |
| 評估 | 樣本多樣性 | **校準度**（calibration）|
| 校驗 | 立即可驗 | 必須等時間到 |

---

### 為什麼這個 HC 重要？

預測是**決策的引擎**——不做預測就無法做投資、政策、醫療、工程。所有 LLM 的「幻覺」、所有領域專家 vs 算命的差別、所有 hedge fund 與散戶的差別，**都落在預測品質上**。

| 場景 | 沒有預測素養的災難 | 有預測素養的對策 |
|------|------------------|----------------|
| 個人財務 | 「這股票會漲」滿倉 All-in | 機率分布 + Kelly criterion |
| 公共衛生 | 「口罩沒用」 | Rt 預測 + 情境規劃 |
| 軟體專案 | 「這個功能下週做完」 | PERT 三點估計 + buffer |
| 國際政治 | 「普丁不會入侵」 | Bayesian belief updating |
| 氣候 | 「2025 是最熱的一年」 | 趨勢 + 變異 + 信心區間 |
| AI 安全 | 「AGI 不會 5 年內到來」 | pre-register + update on evidence |

### 預測的四大類型

| 類型 | 描述 | 範例 | 主要風險 |
|------|------|------|----------|
| **點估計（Point forecast）** | 給單一數字 | 「明天 28°C」 | 偽精確 |
| **區間估計（Interval forecast）** | 給信心區間 | 「明天 25-31°C (95% CI)」 | 寬度選擇 |
| **分布估計（Distribution forecast）** | 給完整 PDF | 颶風路徑機率圖 | 溝通成本 |
| **情境預測（Scenario forecast）** | 給多個可能未來 | 「樂觀 / 基線 / 悲觀」 | 機率難量化 |

### 實作方式

#### 方式一：預測品質評估框架（5 維度）

| 維度 | 問題 | 評分 |
|------|------|------|
| **精確度（Resolution）** | 預測是否明確（日期、數字、事件）？| 模糊的「可能會出問題」 = 0 分 |
| **時間範圍（Horizon）** | 預測期限多長？| 越長風險越大，需更寬區間 |
| **可證偽性（Falsifiability）** | 是否有任何可能的結果能證明預測錯誤？| 「股市會波動」= 不可證偽 = 0 分 |
| **歷史準確度（Track record）** | 預測者過去的 Brier score / calibration？| 沒記錄 = 不可信 |
| **不確定性表達（Calibration）** | 說 70% 對的預測，歷史上真的 70% 對嗎？| 校準差 = 不可用 |

> **核心**：一個**沒有時間、沒有數字、沒有歷史記錄**的「預測」= 意見，不是預測。

#### 方式二：預測方法選擇矩陣

| 情境 | 推薦方法 | 原因 |
|------|---------|------|
| **簡單線性趨勢** | 時間序列分析（ARIMA, ETS）| 數據穩定時最準 |
| **多因素影響** | 多元迴歸、系統動力學 | 拆解因果結構 |
| **高不確定性** | 情境規劃（多個未來情景）| 避免偽精確 |
| **專家判斷** | 德爾菲法（Delphi）| 多輪匿名收斂 |
| **專家 + 模型** | 整合預測（ensemble）| 互補盲點 |
| **極端事件** | 極端值理論（EVT） + 肥尾模型 | 一般模型低估風險 |
| **實時預測** | Kalman filter / 線上學習 | 動態更新 |
| **長期預測** | 預測市場 + 情景樹 | 結合群眾智慧 |

```python
from statsmodels.tsa.arima.model import ARIMA
import numpy as np

def time_series_forecast(series, horizon=12, confidence=0.95):
    """
    ARIMA 預測：點估計 + 區間估計
    """
    model = ARIMA(series, order=(1, 1, 1))
    fitted = model.fit()
    
    forecast = fitted.get_forecast(steps=horizon)
    point = forecast.predicted_mean
    ci = forecast.conf_int(alpha=1 - confidence)
    
    return {
        "point_forecast": point.tolist(),
        "lower_bound": ci.iloc[:, 0].tolist(),
        "upper_bound": ci.iloc[:, 1].tolist(),
        "warning": "ARIMA 假設未來模式不變，若有結構性斷裂會失敗"
    }
```

#### 方式三：校準度（Calibration）— 預測素養的核心

**校準度**：我說「70% 機率」的事件，歷史上是否真的 70% 發生？

```python
def brier_score(predictions, outcomes):
    """
    Brier Score：衡量預測機率 vs 實際結果的距離
    完美 = 0, 最差 = 1, baseline (always 0.5) = 0.25
    """
    return np.mean((np.array(predictions) - np.array(outcomes)) ** 2)

def calibration_curve(predictions, outcomes, n_bins=10):
    """
    校準曲線：分桶看「預測 70% 的事件，是否真的 70% 發生」
    """
    bins = np.linspace(0, 1, n_bins + 1)
    results = []
    for i in range(n_bins):
        mask = (np.array(predictions) >= bins[i]) & (np.array(predictions) < bins[i+1])
        if mask.sum() > 0:
            predicted = np.array(predictions)[mask].mean()
            actual = np.array(outcomes)[mask].mean()
            n = mask.sum()
            results.append({
                "bin": f"{bins[i]:.1f}-{bins[i+1]:.1f}",
                "predicted_prob": predicted,
                "actual_freq": actual,
                "n": n,
                "calibration_error": abs(predicted - actual)
            })
    return results

# 完美校準 = 對角線
# 線在對角線下方 = 過度自信（under-confident）
# 線在對角線上方 = 過度保守（over-confident）
```

**為何校準比準確度重要**：
- 90% 預測 100 次只對 60 次 = 校準差，**不能信**
- 60% 預測 100 次對 60 次 = 校準好，**長期可靠**

> **Brier Score 的反面教材**：Tetlock 的「超級預測家」研究（2015）— 經校準訓練的人 Brier score 0.25 → 0.10，等於把準確率從業餘拉到專業級。

#### 方式四：Bayesian Belief Updating

```python
def bayesian_prediction(prior, likelihood_new_evidence, threshold=0.5):
    """
    預測的核心動作：拿到新證據 → 更新信念
    """
    # prior: 初始信念分布
    # likelihood_new_evidence: P(evidence | hypothesis) for each hypothesis
    
    # 貝氏更新
    posterior_unnormalized = {
        h: prior[h] * likelihood_new_evidence[h]
        for h in prior
    }
    
    # 歸一化
    total = sum(posterior_unnormalized.values())
    posterior = {h: v / total for h, v in posterior_unnormalized.items()}
    
    # 預測
    best_guess = max(posterior, key=posterior.get)
    confidence = posterior[best_guess]
    
    return {
        "prior": prior,
        "posterior": posterior,
        "prediction": best_guess,
        "confidence": confidence,
        "warning": "若 confidence > 0.95：可能是 overconfident，問是否有反證"
    }
```

**實作原則**：
1. **起點**：先給 50/50 不知道（避免 anchor bias）
2. **每個證據**：評估 likelihood ratio
3. **極端時問反例**：信心 > 90% 時，主動找 5 個反例
4. **記錄日誌**：每個預測寫下信心、理由、待驗證日

### 預測偏差與校正

| 偏差 | 描述 | 校正方法 |
|------|------|----------|
| **過度自信（Overconfidence）** | 信心區間太窄 | 用歷史 calibration 重新縮放 |
| **近期偏差（Recency bias）** | 過度重視最近事件 | 看長期 baseline |
| **確認偏誤（Confirmation bias）** | 只注意支持預測的資訊 | 預先宣告反事實條件 |
| **基礎率忽略（Base rate neglect）** | 不考慮長期平均值 | 結合 base rate 估計 |
| **錨定效應（Anchoring）** | 第一個數字影響後續 | 先給區間，後給點 |
| **計畫謬誤（Planning fallacy）** | 低估所需時間 | 參考歷史類似任務 |
| **敘事偏誤（Narrative bias）** | 好故事 → 高信心 | 強制度量 |
| **黑天鵝健忘（Black swan amnesia）** | 忘了尾部風險 | EVT + 壓力測試 |

```python
def recalibrate_overconfidence(raw_predictions, historical_data):
    """
    Platt Scaling：用歷史校準當前預測
    """
    from sklearn.linear_model import LogisticRegression
    # 用歷史 (raw_pred, actual) 學一個 sigmoid 校正
    lr = LogisticRegression()
    lr.fit(historical_data['raw_pred'].reshape(-1, 1), historical_data['actual'])
    
    calibrated = lr.predict_proba(raw_predictions.reshape(-1, 1))[:, 1]
    return calibrated
```

**LLM 特有的預測問題**：

| 問題 | 描述 | 解法 |
|------|------|------|
| **Sycophancy in prediction** | 「用戶希望的答案」取代「真實機率」 | 強制給反方情境 |
| **Anchoring on tokens** | LLM 看到數字就 anchor | 重新生成多版本取中位 |
| **Calibration collapse** | LLM 對所有問題給類似信心 | conformal prediction |
| **Distribution shift blindness** | 訓練分布推測試分布 | OOD detection + abstention |
| **Hallucination as overconfident prediction** | 編造事實 + 高信心 | RAG + 信心約束 |
| **Temporal myopia** | 看不到長程依賴 | chain-of-thought + 外部時間軸 |
| **Verbal-numeric mismatch** | 「很可能」vs 0.7 機率不一致 | 校準到具體數字 |
| **Confidence inflation** | 對所有事都「高」信心 | temperature scaling |

```python
def llm_calibrated_predict(prompt, llm, n_samples=10, temperature=1.0):
    """
    對同一預測問 LLM 多次，估算分布
    """
    import numpy as np
    
    samples = []
    for _ in range(n_samples):
        # 調高 temperature 取得多樣性
        response = llm.generate(prompt, temperature=temperature)
        # 抽取機率
        prob = extract_probability(response)
        samples.append(prob)
    
    return {
        "mean": np.mean(samples),
        "std": np.std(samples),  # 標準差大 = LLM 自己也不確定
        "ci_95": np.percentile(samples, [2.5, 97.5]),
        "warning": "若 std > 0.2：高度不確定，應 abstain"
    }
```

### 反思問題

1. 我的預測有**明確的時間點**嗎？沒有 = 不是預測，是猜測
2. 預測的**類型**是點估計 / 區間 / 分布 / 情境？選擇匹配不確定性
3. 我說「**X% 機率**」的 X%，歷史上真的對 X% 次嗎？算 Brier score
4. 我有沒有**主動找反證**？還是只看到支持預測的證據？
5. 預測的**錯誤成本**對稱嗎？（漏報 COVID vs 誤報疫情的成本）
6. 預測者有**track record**嗎？沒記錄的人 = 不可信
7. 我有沒有被**敘事好聽**的故事說服？（敘事偏誤）
8. LLM 對話：模型說「我確定」時，**校準過**嗎？問它「反例是什麼」

### 經典陷阱

| 陷阱 | 例子 | 解法 |
|------|------|------|
| 偽精確 | 「比特幣 2027-03-15 會到 142,857 美元」 | 給區間，不要假裝精確 |
| 不可證偽 | 「未來會有事發生」 | 必須有可被反駁的條件 |
| 過度自信 | 「我有 95% 確定」 | 看歷史 calibration |
| 近期偏差 | 「今年特別熱 → 地球要毀滅」 | 看長期趨勢 + 變異 |
| 黑天鵝健忘 | 2008 之前沒人預測金融危機 | EVT + 肥尾 |
| 確認偏誤 | 只看支持預測的證據 | 預先註冊反駁條件 |
| 敘事偏誤 | 「這次不一樣」 | 強制度量 |
| LLM 幻覺 | 模型編造事實 + 高信心 | RAG + abstention |
| Planning fallacy | 「這個功能下週做完」 | PERT + buffer |
| 預測者無記錄 | 專家「我覺得會」 | 必須有 Brier 記錄 |
| Anchoring | 第一個數字影響預測 | 先給區間 |
| Survivorship bias | 只看成功預測者 | 也看失敗的 |

### 預測的極限（誠實補充）

| 限制 | 說明 |
|------|------|
| **Nassim Taleb 黑天鵝** | 高影響低機率事件，模型永遠抓不到 |
| **複雜系統不可預測** | 天氣 > 10 天 / 經濟 > 數季：根本性限制 |
| **Lindy Effect** | 越老的預測方法（如 base rate）越可信，新方法要懷疑 |
| **Goodhart's Law** | 預測目標被優化後失效 |
| **Lucas Critique** | 預測改變行為，行為改變使預測失效 |
| **Model risk** | 任何模型都是現實的簡化，總有未捕捉的變數 |
| **Knightian uncertainty** | 連機率都不知道的不確定性（不是 risk） |
| **自身預測悖論** | 預測「大家會恐慌」可能引發恐慌 |

> **平衡**：預測**不完美但必要**。**承認黑天鵝 + 強校準 + 多模型 ensemble + 預先宣告反駁條件** = 現代預測科學的實際做法。

---

**為何這個 HC 重要**：#21 Induction 給你「描述過去」的能力，#22 Prediction 給你「**承擔未來**」的能力。**沒有 #22 的校準素養，你做的 #21 歸納永遠停在描述層；沒有 #22 的時間錨定，你的「預測」是意見，不是知識**。

下次做預測（不論是自己的、科學的、投資的、還是 LLM 的），先問四句：
> 「**什麼時間點、什麼數字、什麼信心**？」
> 「我說的 X% 機率，**歷史上對過 X% 次**嗎？」
> 「**反駁條件**是什麼？什麼結果會讓我承認錯？」
> 「**錯誤成本**對稱嗎？需不需要調整信心？」
