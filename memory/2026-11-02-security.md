1. **先驗證外部曝險（唯讀，5 分鐘）**：從手機熱點或外部主機對本機 **IPv6 `2001:b011:6c09:75cf:513:b375:bdb0:2e34`** 與 22/5900/7070/111/2049 做 TCP 連線測試；同時查路由器是否阻擋 inbound IPv6。**拿到結果前不要對外宣稱安全。**
2. **開主機防火牆（單一指令鏈，順序不可調換，保留既有 SSH 連線）**：
   ```bash
   sudo ufw allow 22/tcp comment 'ssh'
   sudo ufw allow 41641/udp comment 'tailscale'
   sudo ufw --force enable
   sudo ufw status verbose
   ```

   ```bash
   sudo systemctl disable --now nfs-server rpcbind
   ```
