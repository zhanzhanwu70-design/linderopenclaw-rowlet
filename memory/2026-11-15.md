**★ 可跨 session 沿用的三條判讀（不是本次任務的產出，是方法上的）**：
1. **引用論文的成本倍數前先看它是「模型」還是「價格」**。本文頭條 2.2–8.8×／4.4–233.3× 來自 Appendix B 的假想 optimized-serving 價格模型（context factor `r=0.20`，來源是三個 open-weight 模型在 H100 的 throughput 比率均值），而真實 API 是每 token 固定價。用論文自己的 nominal 欄位重算，long-horizon 只有約 0.8–1.6×，**有兩個設定是淨更貴的**。→ **以後任何「省 Nx」的數字都要標明是 nominal 還是 model-based，以及 token 數是否真的下降。**

- **主線**：Red Hat〈Agent harness engineering〉(11-12) 給出判準「**模型能不能違反這個性質？能，就必須在模型之外強制執行**」。最可轉移的一句：**a model that "absorbs permissions" hasn't absorbed permissions — it has dissolved them.** 反直覺後果：**模型越強，弱 harness 越危險，而且在同一個 commit 裡同時發生**。
