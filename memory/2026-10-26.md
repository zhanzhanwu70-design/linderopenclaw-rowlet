
## 每日論文討論（cron 58fe15dc）— 07:00 執行

讀 arXiv:2610.22668 **QEMem — From Relevant Memories to Sufficient Evidence: Rethinking Memory Utilization in LLM Agents**（Li et al., USC + Georgia Tech）。

核心：**relevance–sufficiency gap**。NEMORI 幾乎保留全部紀錄，retrieved episodes 卻只覆蓋 68.8% 問題的 supporting evidence；同一 store 上只換 query-time read path 就 +10.7 pp（Opus 91.43 vs 80.71）。三段式：query-guided discovery（三粒度 + RRF）→ source-grounded ViewCards（claim + evidential role + source + 逐字引文 + 時間）→ sufficiency-guided refinement（只撈 gap、append 不覆寫）。完全不動 memory store。

給 Rowlet 的重點：
1. `memory_search` 現在回「相關清單」不是「證據集」——跨筆記錄問題先列資訊需求再撈第二輪
2. refinement 選擇性原則可抄：不完整才多撈（21.1% vs 7.3%）
3. ViewCard `r_i` 分類法（answer candidate / intermediate fact / temporal constraint / inference support）可直接用於 `MEMORY.md` 條目
4. 引文保真 ≠ 命題被支持（完全蘊含僅 59.6–67.0%）；relative time 一致性僅 60–81% → 記憶改存絕對時間戳
5. 成本甜點：query-guided retrieval + direct answer ≈ Full 的 40–43% 成本、同等分數
