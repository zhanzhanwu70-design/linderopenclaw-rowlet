## 每日論文討論 (23:02 UTC)

**主題**: Agent 上下文處理（Context Processing）
**論文**: arXiv:2606.30005 — "LLM Agents Are Latent Context Managers: Eliciting Self-Managed Context via State Proprioception"
**作者**: Binyan Xu, Haitao Li, Kehuan Zhang (CUHK + LightSpeed/Tencent)

### 存檔位置
- PDF: `raw/references/papers/ai/2606-context-proprioception/2606.30005.pdf`
- Source: `wiki/sources/2606-vista-latent-context-managers.md`
- Reading notes: `raw/references/papers/ai/2606-context-proprioception/reading-2026-07-21.md`

### 核心貢獻
- **VISTA**: 讓 LLM agent 透過 Dashboard 感知自己的 context 狀態，用 archive/retrieve tool 動態管理可見區塊
- **Proprioception**: 模型本體感覺——對自己內部狀態的隱式知覺
- **Lossless handles**: ~0.1K token handle 替代完整 block，需要時 retrieve 回來
- **Proposition 1**: 資訊理論證明 lossy compression 在長 context 時必然失敗（成功率趨於 0）
- **Ablation**: Dashboard 移除 → -13.4%、Archive 移除 → -13.4%、Recovery 移除 → -5.4%

### 討論重點（值得團隊聊）
1. VISTA 的 Dashboard 概念如何應用到我們的 agent 架構？
2. Lossless vs lossy 的取捨——壓縮丟失的精確性值得嗎？
3. 對 Rowlet 自己：目前用固定記憶策略，是否需要動態 archive/retrieve？
