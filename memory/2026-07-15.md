## 23:36 UTC - 每日論文討論：Memory-R2

**論文**：Memory-R2: Fair Credit Assignment for Long-Horizon Memory-Augmented LLM Agents
**作者**：Yan et al., LMU Munich / Siemens, arXiv:2605.21768, May 2026
**PDF**：`raw/references/papers/ai/memory-r2-2026-yan.pdf`

### 核心問題
多 session RL 訓練中，memory 操作（write/update/delete）讓不同 rollouts 的 environment 分歧。GRPO 假設 rollouts 共享同一 environment，但 memory 使得這個假設失效 → credit assignment 不公平。

### LoGo-GRPO 解法
- **Global branch**：正常 GRPO trajectory-level 比較，保留端到端學習
- **Local rerollouts**：從同一 intermediate memory state 重新 rollout m 次，isolated comparisons
- 兩者混合，兼顧 long-horizon 學習 + fair session-level credit

### 關鍵發現
- Chunk-wise construction（分 K 個 chunks 交替 extractor + manager）
- Length-normalized step RL（防輸出長 bias）
- Progressive curriculum：8→16→32 sessions（直接 32-session M-Fail 72.1%，有 curriculum 6.72%）
- 只需 2 個訓練對話就能 zero-shot 泛化到其他 benchmarks
- Qwen2.5-3B F1 +36.5 points（最大受益者是小模型）

### 值得團隊關注
1. **M-Fail 作為記憶覆蓋率診斷**：可用於評估 Rowlet 的 heartbeat 是否真正把關鍵資訊寫入記憶
2. **Progressive curriculum**：隱式相當於 OpenClaw 的從簡單到複雜的 task 設計
3. **Shared-parameter co-learning**：Extractor + manager 共享 backbone 相當於 tool selection + response generation 的 shared policy，可能有 capacity conflict
