**論文核心重點**：
1. Context management 是 **lifecycle** 而非 storage — 五個 moment：architecting, ingesting, scoping, anticipating, compacting
2. **經濟論證**：naïve append = O(n²)，crude summarization = O(n) + accuracy cliff，validated compaction = O(n) + fidelity preserved
3. 五 primitives 涵蓋 individual → organization scope hierarchy
4. Reference implementation: Maximem Synap — LongMemEval 92%, LoCoMo 93.2%

**討論亮點**：
- 呼應 SIRIN：validated compaction 需要 fidelity check，Rowlet heartbeat 前可加 NLI-based trust gate
- ACM framework 為 Rowlet 的三層記憶（Soul/daily/MEMORY）提供了更完整的分析框架
- O(n²) cost scaling 是所有 long-session agent 的核心挑戰
