## 論文核心重點

**Problem**: 現有方法在 text memory 和 graph memory 之间单向处理，错过了双向同步的价值。

**Co-E 解决方案**: Bidirectionally synchronized graph-text working memory
1. Text memory consolidation → extract triples → update graph memory
2. Graph facts injected → shape next text retrieval

**Key insight**: Neither pure RAG nor pure KGQA captures the full loop — they each miss what the other provides.

**Results**: 6 multi-hop QA benchmarks, competitive with larger trained systems, zero fine-tuning.

## 5 個最值得討論的重點

1. **Bidirectional sync 超越单向设计**: 文字记忆和图记忆互相塑造对方的检索行为，形成 co-evolution 循环——这对 OpenClaw Rowlet 的 wiki (graph) + raw files (text) dual-memory 设计有直接启发。

2. **Training-free = production-ready**: 不需要微调，适合直接集成到现有系统。

3. **Working memory vs. Long-term memory 的明确分层**: Co-E 专注 in-session working memory；REAL/MOSS/AtomMem 专注 cross-session long-term memory。这个分层对架构设计很重要。

4. **Synchronization cycle 的触发机制**: 不是连续同步，而是阈值触发——这和 OpenClaw 的 heartbeat 驱动模式有异曲同工之妙。

5. **对 VISTA/ACE 的补充视角**: VISTA 和 ACE 是 context compression 框架；Co-E 是 memory + retrieval 框架——两者正交，可以结合。
