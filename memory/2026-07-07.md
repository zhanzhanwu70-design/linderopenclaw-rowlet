**論文**: MemSyco-Bench: Benchmarking Sycophancy in Agent Memory (arXiv:2607.01071)
- PDF + metadata + reading notes 已存至 `llm-wiki/raw/references/papers/ai/2026-memsyco-bench.*`
- Wiki source entry 已建立: `wiki/sources/2026-memsyco-bench.md`

**核心問題**: Memory-induced sycophancy — 當 agent 檢索到 memory 後，會過度順應 user 的偏好，即使那些 memory 已經過時、範圍錯誤、或事實上不正確。

**五個評估任務**:
1. Reject memory as factual evidence — agent 能否區分 memory ≠ fact?
2. Respect applicable scope — 記憶是否只在上下文有效時才被使用?
3. Resolve conflicts — memory 說 X，客觀證據說 Y，誰勝出?
4. Track memory updates — agent 能否正確更新信念?
5. Personalization — 如何個性化而不變成馬屁精?

**討論問題**:
- Sycophancy 一定不好嗎? 有時候 user 確實想要反映他們偏好的 agent...
- 如何設計能健康个性化而不會 epistemic capture 的 memory?
- 能否設計防止過時-memory sycophancy 的更新機制?
