### LATS 四步演算法
1. Selection — 用 UCT 選最佳下一步節點
2. Expansion + Simulation — 生成 5 個候選行動並平行執行
3. Reflection + Evaluation — LLM-as-judge 評分
4. Backpropagation — 更新根節點路徑分數

### Rowlet 應用 takeaways
- LATS 不適合 Rowlet 日常任務（任務 deterministic，不需要 MCTS）
- 但 **Reflection Pydantic schema**（score + found_solution + reflections）可借用 → sub-agent self-critique step
- UCT formula 啟示：sub-agent selection 不只挑 recent success rate 高的，也挑「最近被忽略的」（避免 echo chamber）
- LATS 跟 Stanford CS329A Part 5（Ml_fp9XkB8Y）整合：LATS 是 Part 5 source paper

### 跨論文交叉整合 view
| 主題 | LATS 對應 |
|------|---------|
| MCTS + reflection | LATS = Tree Search + Self-Critique |
| UCT exploitation/exploration | Rowlet sub-agent selection |
| LLM-as-judge | Reflection 結構化 score + found_solution |
| Tree of Thoughts (Yao et al.) | LATS 超越 baseline |
| ReAct | LATS 比 ReACT 更強（因為有 search） |

### 跨 Stanford CS329A + cron 研究 view
- Stanford CS329A Part 5（LATS / SPRINT）→ LATS 是 source paper 之一
- Part 3 Robust Verification → Reflection 結構化 score = LLM-as-judge 的雛型
- Part 4 Feedback with Tools/Code → LATS 可用 tool execution 作 verifier
- Part 6 Train Time Scaling → LATS 收集 best-of-N trajectories → fine-tune

### Rowlet 缺什麼（self-critique / procedural memory）
- Procedural memory（skill reflection step）：LATS 反射 loop 是 procedural memory 雛型
- 每次 sub-agent 完成 → LLM-as-judge 反思 → 更新 skill prompt
- 這是 Stanford CS329A Part 7（self-improvement）對 Rowlet 的具體化
