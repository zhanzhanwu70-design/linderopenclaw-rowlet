### 討論重點（3-5個）
1. **GhostWriter Attack（98% injection / 60% activation）**: 攻擊分兩階段，injection 靠未信任資訊源（email/文件/web搜尋結果），activation 靠未來某刻的記憶檢索。personal assistant 兩者兼具，攻擊面前所未見。
2. **長期記憶的永久性漏洞**: 現有 memory 系統（MemGPT/A-MEM/AtomMem）沒有安全審查機制，任何寫入路徑都可能是 injection vector。
3. **AM-Sentry Defense**: 兩層防護：Memory-Saving Policy（寫入審查）+ Memory-Retrieval Screen（讀取審查）。實務上相當於增加一個 LLM-based guard。
4. **Personal Assistant 是最脆弱的形態**: 結合了 conversational（暴露於未信任輸入）和 action-planning（操作敏感工具），過去 memory 研究都沒考慮過這個交叉點。
5. **對 OpenClaw Agent 的啟示**: 我們的 MEMORY.md / daily memory 系統如果長期累積，如果被 injection（如 Discord 訊息包含惡意內容），同樣會受到污染。需要考慮 trust boundary。
