## 🌿🦉 Minerva HC #13：Effect Size（效應量）

### 定義

**效應量** — 量化「實際影響程度」的指標，讓我們不只看「有沒有顯著」，更能回答「影響有多大」。

---

### 為什麼需要效應量？

傳統統計課教的是：**p < 0.05 = 顯著 = 有影響**

但這隱藏了一個陷阱：

> **「統計顯著 ≠ 實質顯著」**

- 樣本量 100,000 人時，兩組平均體重差 0.1 kg，p 值可能極度顯著
- 但實際上：0.1 kg 的差異在臨床上毫無意義

**效應量就是為了填補這個漏洞。**

它告訴你：這個影響究竟是「微乎其微」還是「實質重大」。

---

### 核心指標速查表

| 效應量類型 | 適用情境 | 小 | 中 | 大 |
|-----------|---------|-----|-----|-----|
| **Cohen's d** | 兩組平均值差異 | 0.2 | 0.5 | 0.8 |
| **r** | 相關強度 | 0.1 | 0.3 | 0.5 |
| **η²** | ANOVA 變異解釋力 | 0.01 | 0.06 | 0.14 |
| **OR** | 勝算比 | 1.5 | 2.0 | 3.0 |

---

### 實作方式

#### 第一步：永遠同時報告 p + d

```python
# Python：Cohen's d 計算
import numpy as np

def cohens_d(group1, group2):
    n1, n2 = len(group1), len(group2)
    pooled_std = np.sqrt(((n1-1)*group1.var() + (n2-1)*group2.var()) / (n1+n2-2))
    return (group1.mean() - group2.mean()) / pooled_std

# 實驗組 vs 對照組
d = cohens_d(experiment_group, control_group)
# |d| < 0.2 → 微小；0.2-0.5 → 小；0.5-0.8 → 中；> 0.8 → 大
```

#### 第二步：用信賴區間（CI）補足

單獨一個 d 值仍不夠——報告 **d 的 95% CI**，才知道這個估計有多精確。

#### 第三步：對照情境解讀

```
藥物降血壓實驗：
  - d = 0.3 → 統計顯著，但平均只降 3 mmHg，臨床上可能無感
  - d = 0.9 → 不只顯著，平均降 10 mmHg，臨床有意義
```

---

### 在 AI / LLM 評測中的應用

Effect Size 概念在模型比較中經常被忽略：

| 錯誤做法 | 正確做法 |
|---------|---------|
| 「Model A 準確率 72% vs Model B 68%，p < 0.01，所以 A 更好」 | 計算 Cohen's d，搭配 CI，判斷「好多少」 |
| 忽略 base rate 直接報告相對提升 | 報告絕對效應量 + 情境意義 |

這也是為什麼 LLM 排行榜常常誤導——只看分數差異，不看效應量。

---

### 與其他 HC 的關聯

- **#12 Descriptive Statistics** — 效應量是描述統計的進階應用
- **#14 Confidence Intervals** — CI 搭配效應量才是完整報告
- **#18 Significance** — 統計顯著只是門檻，效應量才是實質內涵
- **#10 Conditional Probabilities** — 效應量與條件概率同屬「量化真實影響」框架

---

**下次看到統計結果時，多問一句：「效應量是多少？」** 
統計顯著只是告訴你「不是零」，效應量才告訴你「實際有多少」。
