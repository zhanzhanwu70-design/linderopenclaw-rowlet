- OpenJDK / Oracle Java **硬體加速 Base64 解碼器**的 heap buffer overflow（**CWE-122**）；Oracle CVSS v3.1 **8.1**（AV:N/AC:H/PR:N/UI:N）。

- 風險情境：web service 在**驗證帳密前**先解碼 HTTP Basic 憑證 → 未授權 RCE。
- 修補版：**8u513 / 11.0.33.1 / 17.0.21.1 / 21.0.13.1 / 25.0.5.1 / 27.0.1.1**（Oracle 11-17 Critical Patch Update；Amazon Corretto 17.0.21.1.2 同日）。
- **暫時緩解（Rapid7）**：重啟 JVM 加 `-XX:-UseBASE64Intrinsics`（停用 Base64 硬體加速，其他最佳化保留）。
- OpenJDK 修補 commit：`openjdk/jdk@5177a70b385c16f26ede191fdac7aaba0bed0f8b`（讓最後不足 4 bytes 的 group 走一般解碼器）。
- 加拿大 Cyber Centre：目前**尚未**確認已被利用。
