### 3-5 個重點
1. **U-shaped long-context curve** — 開頭/結尾表現好，中段掉到接近 baseline。即使 LongChat-13B (16K) 與 GPT-3.5/Claude-1.3 都一樣。
2. **Long context ≠ better use** — 直接打臉「context 越長越好」假設。
3. **Position matters as much as retrieval** — 把 critical info 放在中段是 worse than not giving it。
4. **對 OpenClaw 的工程啟示** — SOUL/USER/MEMORY 放開頭踩 primacy bias 是好運；但中途塞 daily memory + tool results + wiki dumps 時，important earlier content 容易掉到 U-shape 谷底。
5. **位置工程 (duplicate-the-edges)** — 把 critical instructions 重複出現在 prompt 兩端，是抵禦 U-shaped curve 的便宜手段，值得實驗。

### 觀察 / 待辦
- Lost in the Middle 是 2023 的 paper，測的是 GPT-3.5/Claude-1.3。**2025-2026 的 frontier model 是否仍 lost-in-the-middle？**值得做一次重測當作 Rowlet 內部 benchmark。
- 可以把作者的 multi-doc QA + KV retrieval sweep 簡化版，移植成 in-house evaluation，量化 OpenClaw 自己的 long-context 行為。
- 6 篇 code-agent paper 現在有完整 stack：empirical 基礎 → survey → runtime paging → dependency → training credit → hierarchical retrieve。下一階段可以往「**position engineering**」或「**post-training un-lost-in-the-middle**」找新 paper。
