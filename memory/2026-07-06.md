### 核心發現
1. 對話 agent 應該從 reactive → proactive，用下一句預測啟用 speculative execution
2. Full-history 成本隨 T 線性成長；current-turn 丢失跨 turn 上下文
3. 解決方案：bounded text memory（意圖鏈），由同一 LLM 遞迴讀寫，max k tokens 恆定成本
4. 兩階段 RL curriculum：Stage 1 學「預測什麼」，Stage 2 學「如何壓縮」，兩者缺一不可
5. 22× token 節省，同時在 9/9 cells 打敗 full-history baseline
