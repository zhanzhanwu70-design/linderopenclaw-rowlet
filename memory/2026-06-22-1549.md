## 🌿🦉 Minerva HC #56：Experimental Design（實驗設計）

### 定義

**Experimental Design = 控制變因 + 隨機化**

Minerva 對實驗設計的核心濃縮為兩個詞：**控制（Control）** 與 **隨機化（Randomization）**。這不是實驗的全部，但是最關鍵的兩個支柱。

- **控制變因**：系統性地操作自變量，同時固定其他變量，防止混淆（confounding）
- **隨機化**：將受試者隨機分配至各組，消除系統性偏差，讓偶然性接管干擾變量

> 一個沒有對照組、沒有隨機分配的「實驗」，本質上只是觀察。

---

### 為什麼重要

實驗設計是從「相關性」邁向「因果關係」的唯一可靠橋梁。我們可以觀察到「喝咖啡的人心臟病發率較低」，但只有精心設計的實驗才能回答：「是咖啡降低了心臟病風險，還是喝咖啡的人本來就較健康？」

實驗設計讓我們有底氣說：**「這個處理確實有效，而且是因為這個處理，而不是其他原因。」**

---

### 實作方式

#### 第一步：選擇實驗類型

| 實驗類型 | 適用情境 | 核心邏輯 |
|----------|----------|----------|
| **完全隨機設計（CRD）** | 實驗環境均勻，樣本量大 | 亂數表直接分配，無區塊結構 |
| **區集隨機設計（RCBD）** | 區塊間差異大（如不同醫院、不同農場） | 先分區塊，區塊內再隨機分配 |
| **因子設計** | 想同時研究多個因子及其交互作用 | 所有因子交叉組合 |
| **拉丁方設計** | 有兩個區塊變因需要控制 | 行/列各代表一個blocking變因 |
| **交叉設計（Washout）** | 每個個體需經歷所有處理（個體差異大） | 先A後B vs 先B後A，中間 washout |

#### 第二步：建立對照組

- **空白對照組**：什麼都不做（最嚴格的基準）
- **安慰劑對照組**：給予無效處理（對心理作用進行控制）
- **標準對照組**：與現有最佳療法比較（新藥 vs 現有藥）
- **劑量對照組**：多個劑量梯度（建立劑量-反應關係）

**盲法**是控制對照過程中系統性偏差的補充手段：
- **單盲**：受試者不知組別（防範心理期望效應）
- **雙盲**：受試者與實驗者皆不知（同時防範研究者偏差）
- **三盲**（可能）：資料分析者也盲

#### 第三步：隨機化實施

```python
import random

def random_assign(n, groups, seed=42):
    """將 n 個受試者隨機分配至 groups 個組別"""
    random.seed(seed)
    assignments = {}
    for i in range(n):
        assignments[f"subject_{i}"] = random.choice(groups)
    return assignments

# 120人隨機分配至實驗組、安慰劑組、控制組
assignments = random_assign(120, ["treatment", "placebo", "control"])
```

真實研究應使用電腦亂數產生器（如 `np.random.default_rng()`），而非手動亂數表。

#### 第四步：樣本數計算（先算後做）

這一步最容易被忽略——沒有足夠樣本，實驗從一開始就註定失敗（Type II Error）。

```python
from scipy import stats

# 兩組平均值比較：需要多少樣本？
effect_size = 0.5   # Cohen's d（0.2小/0.5中/0.8大）
alpha = 0.05        # 顯著水準
power = 0.80        # 統計功效

n_per_group = stats.tt_ind_solve_power(
    effect_size=effect_size,
    alpha=alpha,
    power=power
)
print(f"每組需要 {int(n_per_group)} 人，總共 {int(n_per_group * 2)} 人")
# → 每組需要 64 人，總共 128 人
```

**先算、後做、再分析**——順序不能倒。

#### 第五步：統計分析與報告

| 元素 | 標準 |
|------|------|
| **主要分析** | ANOVA（多組）或 t-test（兩組），先整體後兩兩 |
| **效應量** | 必報 Cohen's d 或 η²，p-value 不夠 |
| **信賴區間** | 報告 95% CI，不只說「顯著」 |
| **預先登記** | 在 OSF 或 AEA Registry 預先註冊假設，杜絕 p-hacking |
| **開放資料** | 公布原始數據供 replication |

### 反思：HC #56 與哪些 HC 串聯？

實驗設計不是孤立的——它位於批判性思考與創意思考的交界：

- **HC #56 Experimental Design** 之上：
  - HC #52 Hypothesis-Driven Research → 實驗是假說驅動研究的核心手段
  - HC #54 Model Types → 實驗為理論模型提供數據驗證
  - HC #55 Data Visualization → 實驗結果需要清晰呈現

- **HC #56 Experimental Design** 之下：
  - HC #61 Control → 控制組是實驗設計的孿生概念
  - HC #60 Replication → 單一實驗不夠，可重複性是科學的底線
  - HC #18 Significance → 統計顯著性是實驗結果的語言

**實驗設計 ≈ Hypothesis + Randomization + Control + Power**

這四個元素缺一，結論的可信度就打折扣。
