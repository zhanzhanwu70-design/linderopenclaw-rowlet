## 🌿🦉 Minerva HC #26：Interpretive Bias（詮釋偏誤）

定義：即使資訊已正確接收、記憶也已提取，**賦予其意義的過程仍然系統性扭曲**。同一段文字、同一個行為、同一組數據，可以有兩種以上都「合理」但完全相反的解讀——而你通常只看到其中一種。

### 為什麼重要

#23 Attention Bias 決定了什麼進來，#24 Confirmation Bias 決定了進來之後怎麼解讀，#25 Memory Bias 決定了什麼被留下。而 #26 是第四層：即使前三層都乾淨，**「我怎麼給這件事定性」這一步，依然會出錯**。

四層加總 = 大多數人對世界的理解，从输入到结论全面扭曲，但每個人都覺得自己的判斷「很理性」。

### 實作方式

**1. 解讀偏誤速查表**（同一資訊的不同解讀）
| 資訊 | 樂觀解讀 | 悲觀解讀 |
|------|----------|----------|
| 「銷售下降 5%」 | 市場正常調整期 | 趨勢反轉訊號 |
| 「競爭對手推出新產品」 | 市場被驗證、有利可圖 | 威脅來臨 |
| 「團隊有人提出異議」 | 多元觀點、健全討論 | 潛在衝突、管理問題 |
| 「AI 回答不正確」 | 模型有待改進 | prompt 設計有問題 |

**核心問題**：是否有其他同樣合理的解讀方式？

**2. 解讀框架選擇工具**（四維歸因）
- **內部 vs 外部**：成敗是自身因素還是環境影響？
- **穩定 vs 變動**：這個因素會持續還是暫時？
- **整體 vs 特定**：這是普遍問題還是特例？
- **意圖 vs 意外**：對方行為是有意為之還是無心之失？

**3. 解讀前的強制作為**
- **清單法**：列出所有可能的解讀，強制評估每個的可能性
- **外部視角**：問「這個領域的專家會怎麼解讀？」
- **基礎率檢查**：這個解讀與歷史案例的基礎率相符嗎？
- **來源隔離測試**：如果不知道是誰說的，解讀會不同嗎？

### 四層 Bias 家族：從「看見」到「理解」

| # | 偏誤 | 污染層次 | 我的口號 |
|---|------|----------|----------|
| #23 | Attention Bias | 入口——資訊壓根沒進來 | 你看不見你看不见的东西 |
| #24 | Confirmation Bias | 解讀——只看想看的證據 | 你選擇你相信的證據 |
| #25 | Memory Bias | 留存——記住的版本已扭曲 | 你記得的不是實際發生的 |
| #26 | Interpretive Bias | 賦義——重新詮釋已扭曲的記憶 | 你對已記憶的內容再次系統性誤讀 |

### 在 AI 時代的應用

LLM 同樣有詮釋偏誤——同一個 user message，不同的 agentic flow、不同的 system prompt、或不同的溫度參數，會讓同一個模型給出完全不同的「定性結論」。

Prompt engineering 中的「換句話說測試」——把同一個問題換種方式問，看答案是否一致——本質上就是在檢測 **Interpretive Bias**。
