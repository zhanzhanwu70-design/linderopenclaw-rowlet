### 論文：Customer-Agent (arXiv:2606.07995)
- **標題：** Customer-Agent: Overcoming Context Limitations in Ultra-Long Shopping Trajectories via Tool-Augmented Agents and RLVR
- **作者：** Hongye Liu et al. (Amazon + Duke University)
- **主題：** Agent 上下文處理（Context Processing）
- **Saved to:** `raw/references/papers/ai/2606-customer-agent.pdf`
- **Source entry:** `wiki/sources/2606-customer-agent.md`
- **Map 更新:** `wiki/maps/code-agent.md`（新增條目）

### 核心重點（最值得討論的 5 點）

1. **外置化 context 突破固定 window 限制**：不是壓縮，而是把長軌跡存成外部文件（SQLite/JSON），agent 用 SQL 查询检索 relevant fragments。理论上可扩展到百万/十亿 tokens。

2. **ShopTrajQA Benchmark（32k/64k tokens）**：基于真实 ESCI 产品数据 + LLM 模拟购物轨迹，每个 QA 附可执行 SQL，答案可自动验证。Benchmarking 揭示主流 LLM 在长轨迹上性能显著下降。

3. **RLVR 训练范式**：Reinforcement Learning with Verifiable Rewards——不用 learned reward model，用任务特定的 rule-based 验证信号。SFT 冷启动 → RL fine-tune，教会 agent 主动调用工具。

4. **分离检索与推理**：当 model 必须同时做"大海捞针"和推理时，两件事都做不好。Tool-augmented retrieval 让 model 只专注推理。

5. **SQL 作为结构化外部记忆接口**：非向量相似度，而是程序化查询。更适合有 schema 的数据（购物轨迹、日志等），但非结构化数据需要不同接口。
