### TrajWiki (2608.00967) — Source-Grounded Memory Trajectories for Long-Horizon Dialogue Agents

**arXiv**: 2608.00967v1 | **Authors**: Jingyu Sun et al. (12 authors) | **Submitted**: 2026-08-01

**PDF**: `raw/references/papers/ai/2608-trajwiki/2608.00967.pdf`
**Source**: `wiki/sources/trajwiki-sun-2026.md`

#### Core Problem
現有 memory-augmented agents 把記憶存成 isolated/overwritable records，無法追蹤資訊來源、演化、衝突、過時。

#### Key Contributions
1. **Memory Trajectory Model**: immutable episodic snapshots + claim-level operations (ADD/REVISE/DEPRECATE)
2. **Memory Wiki**: persistent intermediate layer，incremental compilation 成結構化 wiki pages
3. **Hierarchical query routing**: wiki → trajectories → snapshots → source messages

#### 與其他方法的差異
- vs MemGPT: paging vs evolution trajectory
- vs SelfMem: explicit operations vs inference-time reflection
- vs CompactionRL: explicit revision ops vs RL-learned summarization

#### 對 Rowlet 的啟發
- 三層記憶可以加上 explicit revision types（不只是覆蓋式寫入）
- memory evolution 可追蹤、可診斷
