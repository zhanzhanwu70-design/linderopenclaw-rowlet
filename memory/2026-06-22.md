## Minerva HC #28：Nonfiction（非虛構文本分析）

**定義**：非虛構文本分析與評估——批判性地閱讀真實世界資訊（新聞、報導、回憶錄、論文、部落格等），區分事實與詮釋，檢驗證據品質與作者立場。

### 核心框架

**五維分析法**：
1. **事實聲稱**：作者說了什麼？可驗證嗎？
2. **證據品質**：一手 vs 二手？資料來源？
3. **論證結構**：前提→結論推論是否有效？
4. **作者立場**：潛在偏見或利益衝突？
5. **遺漏檢查**：忽略了什麼觀點或證據？

### 實作工具：SIFT 快速評估
1. **Stop**：情緒化嗎？先停下來
2. **Investigate**：來源專業性？
3. **Find better coverage**：其他來源怎麼說？
4. **Trace claims**：回到原始來源

### 與其他 HC 的連結
- **#4 Source Quality**：Nonfiction 是 Source Quality 的實作場域
- **#27 Context**：文本解讀不能脫離脈絡
- **#1 Assertions**：Nonfiction = 一系列 Assertions 的集合
- **#20 Logical Fallacies**：檢查 Nonfiction 中的推論陷阱
- **#24 Confirmation Bias**：作者和讀者都可能只看到想看的

### 為何重要
假新聞、標題黨、選擇性報導——這些都是「沒有被批判閱讀的非虛構文本」。#28 Nonfiction 是資訊時代的**基本識讀能力**：能讀、會分辨、不被操控。

### 一句話
> **每一篇「真實報導」都是經過選擇、詮釋、框架建構的產物。批判閱讀非虛構文本，是抵抗認知被操控的第一道防線。**

## Minerva HC #27：Context（脈絡）

**定義**：情境如何影響意義。

### 為何重要

脈絡失真（decontextualization）是最常見的認知陷阱：媒體掐頭去尾引用、統計數據脫離取樣背景、歷史事件被選擇性引用——不懂脈絡，就像只看剪影認人。

### 實作方式

**脈絡層次分析**：
- 歷史脈絡：什麼時期？有什麼時代背景？
- 文化脈絡：這個文化如何看待這個主題？
- 社會脈絡：當時的社會結構是什麼？
- 作者脈絡：作者的立場、經歷、動機是什麼？
- 文本脈絡：前後文說了什麼？有沒有被斷章取義？

**脈絡依賴性檢查**：
1. 結論是否只在特定脈絡下成立？
2. 脈絡改變，結論是否仍然有效？
3. 論述者是否故意忽略了重要脈絡？

**反事實脈絡測試**：在不同的時間/地點/社會位置脈絡下，會有什麼不同？

### 與其他 HC 的連結
- **#26 Interpretive Bias**：脈絡缺失 → 詮釋偏誤
- **#4 Source Quality**：Source Quality 是 Context 的實作工具
- **#28 Nonfiction**：非虛構文本是脈絡失真最常見的戰場

### 一句話
> **不懂脈絡，就沒有真正的理解。**

## 🌿🦉 Minerva HC #31：Music（音樂批判閱讀）

**定義**：音樂的結構與表達分析——批判性地拆解音樂作品的形式元素、風格特徵與詮釋意義，區分「聽起來如何」與「為何有效」。

### 核心框架：三層次分析

**第一層：音樂內部元素**
| 層次 | 觀察什麼 |
|------|----------|
| **旋律** | 音高輪廓、動機發展、重複與變形 |
| **和聲** | 和弦進行、調性關係、功能和聲 |
| **節奏** | 拍子、速度、節奏型、分句結構 |
| **織體** | 單聲／主調／複調／主音伴奏 |
| **音色** | 樂器組合、動態變化、聲部層次 |
| **結構** | 曲式（呈示→發展→再現）|

**第二層：脈絡分析**
| 方法 | 核心問題 |
|------|----------|
| 歷史分析 | 創作時期的風格慣例？ |
| 社會分析 | 音樂與社會政治脈絡的關係？ |
| 作曲家分析 | 作者風格指紋？創作動機？ |

**第三層：批判性聆聽問題**
- 這首作品的「內容」是純音樂還是標題音樂？
- 這個版本／演奏的詮釋是否合理？
- 為何我感受到情緒反應？音樂手法是什麼？

### 實作工具：FORM 分析（Standard Music Journal）
> **F**orm（曲式）| **O**rnaments（裝飾）| **R**hythm（節奏）| **M**elody（旋律）| **M**elody + Harmony combined

或更系統性的：**八要素框架**（Tempo, Dynamics, Melody, Texture, Harmony, Structure, Timbre, Style）逐一過篩。

### 與其他 HC 的連結
- **#30 Visual Art**：音樂和視覺藝術都是「非語言語境中的推理與表達」
- **#29 Poetry**：詩與音樂共享節奏、意象、象徵等批評工具
- **#36 Emergent Properties**：一首曲子是「音符 + 結構」的湧現，不是元素相加
- **#27 Context**：不了解巴洛克／古典／浪漫時期的風格規範，無法批判貝多芬
- **#20 Logical Fallacies**：音樂評論中也會犯「呼應偏好」（appeal to authority）等謬誤

### 為何重要
你每天聽 Spotify／YouTube，但有沒有真正「讀懂」過一首歌？#31 Music 是感官素養的關鍵錬節：

1. **聆聽深度**：從被動接受 → 主動分析
2. **跨文化理解**：不同文化的音樂美學蘊含不同認知框架
3. **批判消費**：能區分「行銷出來的好聽」和「真的好」

> **一句話**：
> **「這首歌好聽」不是分析；「和弦進行製造了什麼情緒張力、為何有效」才是。**

## Minerva HC #34：Constituent Parts（構成要素）

**定義**：拆解整體為部分——識別、列舉、分類、評估任何系統、組織、或概念的整体構成要素，並理解要素之間的層級與依賴關係。

### 為何重要

**構成要素分析**是系統性思考的第一刀。不先問「有什麼部分」，就無法問「部分如何互動」（#35）、或「湧現了什麼屬性」（#36）。#34 是 #35 和 #36 的**前置功夫**：分解不清，系統分析就是空中樓閣。

現實中的失敗案例：
- 併購失敗：公司當整體買，卻沒分析各部門的構成要素是否相容
- 政策失效：只看宏觀目標，沒拆解執行鏈上的構成要素（人/錢/法/激勵）
- 系統崩潰：忽略「看起來不重要」的構成要素，結果它們是關鍵依賴節點

### 實作方式

**五步構成要素分解流程**：
1. **識別整體邊界**：這個系統的範圍是什麼？什麼在內，什麼在外？
2. **列舉所有要素**：MECE 原則——相互獨立、完全窮盡（不遺漏、不重疊）
3. **分類分組**：按功能、層級、性質分組（核心 vs 周邊、硬體 vs 軟體 vs 人）
4. **關係分析**：哪些是依賴關係？哪些是競爭關係？是順序依賴還是平行協作？
5. **權重評估**：移除哪個要素會讓整體功能實質崩潰？哪些是「看起來有但少一兩個也無所謂」？

**構成分析 vs 系統分析對比**：

| 維度 | 構成分析（#34） | 系統分析（#35） |
|------|----------------|----------------|
| 重點 | 靜態組成 | 動態互動 |
| 核心問題 | 「有什麼部分？」 | 「部分如何互動？」 |
| 刻意忽略 | 關係與互動 | 部分的獨立性 |
| 適用場景 | 結構問題、盤點、清點 | 流程問題、優化、故障排除 |

> **構成分析告訴你火車有哪些車廂，系統分析告訴你車廂之間怎麼連接、動力怎麼傳遞。兩者缺一不可，但 #34 在先。**

**三個診斷性問題**：
1. 這個整體的**最少必要要素**是什麼？（MECE + 核心識別）
2. 要素之間是**互補還是競爭**關係？（互補 = 1+1>2，競爭 = 資源争夺）
3. 移除某要素會如何影響整體功能？（破壞性測試思維）

### 與其他 HC 的連結
- **#35 Systems Dynamics**：#34 靜態分解 → #35 動態互動分析
- **#36 Emergent Properties**：湧現屬性來自構成要素的互動，不是要素本身
- **#33 Levels of Analysis**：構成要素往往存在於不同分析層次（微觀粒子 → 巨觀結構）
- **#38 Networks**：構成要素 + 關係 = 網絡節點 + 連邊
- **#48 Right Problem**：正確問題需要正確的構成要素分解——拆錯地方，問題永遠解不了

### 一句話
> **不會拆，就不會建。不先問「有什麼部分」，所有系統分析都是沙灘上的城堡。**

## Minerva HC #35：Systems Dynamics（系統動力學）

**定義**：分析系統中**反饋迴路（feedback loops）**與**時間延遲（delays）**如何共同塑造系統行為。

### 四個核心概念

| 概念 | 說明 | 現實類比 |
|------|------|----------|
| **正反饋** | 雪球效應，放大初始變化 | 網路效應、病毒傳播 |
| **負反饋** | 系統自動對抗偏移，尋求穩定 | 恒温器、市場供需 |
| **時間延遲** | 行動與後果之間的時間差 | 氣候變遷、人口政策 |
| **存量-流量** | 累積量與改變速率 | 人口、庫存、信任 |

### 五種系統行為模式
1. 指數成長（S曲線）2. overshoot & collapse 3. 振盪 4. 均勻錨定

### 干預三原則
- 提前干預（延遲越長越需要提前）
- 找槓桿點（最小改變最大影響）
- 保留負反饋（過度干預破壞韌性）
