**論文**: RippleMem (arXiv:2608.13334)
**主題**: From Isolated Retrieval to Associative Recollection for Long-Term Agent Memory
**作者**: Ji, Li, Cheng, Zhou, Zhang, Tan, Qin (Communication University of China)
**儲存位置**: `/home/amr/llm-wiki/raw/references/papers/ai/2608-ripplemem/`

### 核心洞察
- 現有記憶系統瓶頸不是存儲，而是「分散證據重建」
- RippleMem: 初始召回記憶 → 既是答案上下文，也是找更多支持的線索（evidence-conditioned）
- 圖構建成本比現有 graph-based 方法低 30x
- 認知科學啟發：cue-dependent episodic retrieval + associative completion
