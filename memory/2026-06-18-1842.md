## 🌿🦉 Minerva HC #16：Regression（迴歸分析）

### 定義

**迴歸** — 把多個變數的關係用一條曲線（或一張超平面）量化出來，讓「A 影響 B」這個模糊的說法變成一個**可以被反駁的數字**。

---

### 為什麼需要迴歸？

人天生會把觀察到的模式當成因。迴歸是對抗這種直覺的工程工具——它強迫你回答三個問題：

1. **控制其他變數之後**，X 對 Y 還有影響嗎？
2. 這個影響**多大**？（係數 + 信賴區間）
3. 這個影響在統計上**是不是真的**？（p 值、效應量）

沒有迴歸，所有「X 影響 Y」的說法都只是**敘事，不是論證**。

---

### 核心觀念速查

| 概念 | 意思 | 何時用 |
|------|------|--------|
| **OLS** | 最小化 Σ(yᵢ - ŷᵢ)² | 線性、解釋導向 |
| **β 係數** | X 改變 1 單位，Y 平均改變多少 | 量化影響 |
| **R²** | 模型解釋的變異比例 | 模型整體配適度 |
| **VIF** | 變數被其他變數解釋的程度 | 偵測多重共線性 |
| **Lasso (L1)** | 懲罰係數絕對值 | 自動特徵選擇 |
| **Ridge (L2)** | 懲罰係數平方 | 防止係數爆炸 |

> **關鍵警示**：迴歸係數只能告訴你「控制了已知變數後仍有相關」。**因果**還需要實驗設計（RCT）、IV、DiD 等方法。

---

### 實作方式

#### 方式一：scikit-learn 工具棧

```python
from sklearn.linear_model import LinearRegression, Ridge, Lasso
from sklearn.preprocessing import PolynomialFeatures, StandardScaler
from sklearn.pipeline import make_pipeline

# 簡單線性迴歸
model = LinearRegression()
model.fit(X_train, y_train)
print(f"R² = {model.score(X_test, y_test):.3f}")

# 多項式迴歸（捕捉非線性）
poly_model = make_pipeline(
    PolynomialFeatures(3),
    StandardScaler(),
    Ridge(alpha=1.0)   # L2 防止高次項係數爆炸
)
poly_model.fit(X_train, y_train)

# Lasso 自動特徵選擇
lasso = Lasso(alpha=0.1)
lasso.fit(X_train, y_train)
# 係數歸零的特徵 → 被淘汰
```

#### 方式二：statsmodels 拿完整報表

```python
import statsmodels.api as sm
X_with_const = sm.add_constant(X)        # 記得加截距
model = sm.OLS(y, X_with_const).fit()
print(model.summary())
# 重點看：coef（影響大小）、P>|t|（顯著性）、[0.025, 0.975]（CI）
```

#### 方式三：診斷檢查清單

| 診斷項目 | 問題信號 | 解法 |
|----------|----------|------|
| 線性假設 | 殘差圖有曲率 | 對數/多項式轉換 |
| 常態性 | Q-Q plot 偏離對角線 | Box-Cox 轉換 |
| 同方差性 | Breusch-Pagan < 0.05 | 改用 robust SE |
| 多重共線性 | VIF > 10 | 移除/合併/PCA |
| 異常值 | Cook's distance > 1 | 移除或分開分析 |

#### 方式四：解釋 vs 預測 vs 因果

| 導向 | 推薦模型 | 評估指標 |
|------|---------|---------|
| **解釋** | OLS / Elastic Net | 顯著性、β 可解釋性 |
| **預測** | Gradient Boosting / RF | RMSE、MAE |
| **因果** | RCT、IV、DiD、RD | 平均處理效應 (ATE) |

> **判斷原則**：問題問「為什麼」→ 偏解釋；「明天會怎樣」→ 偏預測；「介入會有用嗎」→ 必須用因果推論。

### 在 AI / LLM 評測中的應用

迴歸在 LLM 評測圈被嚴重低估：

| 場景 | 正確做法 | 錯誤做法 |
|------|---------|---------|
| 多基準綜合排名 | 控制模型規模、token 數後做迴歸 | 直接按總分排名 |
| A/B 測試 prompt | 評測指標對 prompt 變體做迴歸 | 只看平均分 |
| 模型比較 | 控「題目難度」共變數 | 把簡單題高分當模型強 |

**特別提醒**：「模型 A 比 B 高 1.2 分」的報導，**沒控制 prompt 變異、題目難度、評分者隨機性**，本質上是沒做迴歸的粗糙比較。#13 Effect Size + #14 CI + #16 Regression 三件套必須一起用。

### 與 #15 Correlation 的關鍵差別

| 面向 | Correlation | Regression |
|------|------------|------------|
| 變數角色 | 對稱 | 不對稱（X 預測 Y） |
| 輸出 | 單一 r 值 | 完整函數 y = f(X) |
| 多元擴展 | 偏相關 | 多元迴歸（一次控多個變數） |
| 因果暗示 | 完全無 | 「控制後的關聯」 |

**記憶口訣**：Correlation 問「有多相關？」，Regression 問「X 變動時 Y 怎麼變？」

---

### 反思問題

1. 我的模型假設是線性的嗎？會不會是 U 型或門檻效應？
2. X 變數之間會不會互相解釋（多重共線性）？
3. 殘差圖長什麼樣？有沒有被忽略的結構？
4. 這個 β 在我的問題領域**有實質意義**嗎？
5. 我能給出因果解釋，還是只能說「控制後的關聯」？

---

**為何這個 HC 重要**：

迴歸是**把相關變成可檢驗論證**的工程工具。沒有它，#15 Correlation 只能告訴你「有沒有」，沒辦法告訴你「控制之後還有沒有」「多大」「多確定」。

在 LLM 評測、社會科學、醫學研究、商業分析、工程診斷——任何涉及「量化影響」的場景，迴歸都是基本功。

下次看到「X 影響 Y」的報導，多問一句：
> 「控制了什麼變數？β 是多少？信賴區間多寬？」
