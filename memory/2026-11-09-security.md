## 三、今日實際落地（user 層、可逆、已驗證）

### ★ 1. **openclaw-memory skill：6 個 CVE → 0**（昨日的殘餘債今天清掉）<!-- project: github.com/zhanzhanwu70-design/linderopenclaw-rowlet -->
- 根因：`@xenova/transformers` 是 **optionalDependency**，npm 只在安裝當下拉 `onnxruntime-web@1.14.0 → onnx-proto@4.0.4 → protobufjs@6.11.6`（宣告 `^6.8.8`）與 `sharp@0.32.0`；`npm audit fix` 對這條鏈**無解**（它會想降級 `@xenova/transformers` 到 1.4.2 = semver-major，會砸掉 embeddings）。
- 解法：走 **npm `overrides`**（不動 semver、不動 optional dep 版本）→ `protobufjs ^7.6.6`、`qs ^6.17.1`、`sharp 0.35.5`。
- 驗證：`npm audit` **6 → 0**（crit 0 / high 0 / mod 0）｜protobufjs 6.11.6→**7.6.6**、qs 6.14.3→**6.17.1**、sharp 0.32.6→**0.35.5**（libvips CVE-2026-33327/33328/35590/35591 + libheif + librsvg 全修）｜**onnx-proto 在 protobufjs 7 下 encode/decode round-trip 實測 OK**（producerName 往返一致）｜`protobufjs/minimal` 可載入｜onnxruntime-web 可載入｜`@xenova/transformers` `pipeline` 仍可用｜`better-sqlite3` 因 ABI 變更（127→137）**已 rebuild**，原生模組載入 OK｜`src/index.js` + 3 個 hooks 全部 import OK、`getMemoryManager()` 初始化成功（openai embeddings）｜全部 `node --check` 通過。
- 教訓：**optional dependency 會把整個漏洞鏈鎖死在舊版**；`overrides` 比降級上游安全得多。

### ★ 2. **a2a-gateway extension：runtime 8 → 1**（critical 2 → 0）<!-- project: github.com/zhanzhanwu70-design/linderopenclaw-rowlet -->
