   - 發生什麼：LangSmith LLM Gateway 公開 beta。設計：centralized governance layer 在 agents 與 models 之間，**不嵌入每個 agent 程式**；4 種控制：（a）**cost controls** — Org / Workspace / API key / User 4 層 spend tracking，cap hit 回 402；（b）**rate limits** — 同 4 層防 runaway traffic；（c）**model fallbacks** — provider outage 自動切；（d）**sensitive data handling** — 在 gateway 層做 PII redact。LangChain 自家 narrative：「one place to enforce runtime controls across agents, models, and providers, helping them consistently govern model usage **while avoiding vendor lock-in**」。內部案例：customer service agent 撞 provider outage；coding agent overnight retry loop 10,000 calls 變 four-figure invoice — 兩個都是 post-hoc visibility 不夠的失敗模式。

3. **earendil.com 〈The session you cannot take with you〉（HN #1 381 pts / 89 comments，2026-07-30）— 第一次 vendor-level 公開質疑「inference provider 把 session 鎖住」：reasoning tokens 是 opaque encrypted blobs、compacted context 只有原 provider 能解密、subagent 指令藏在 application 後面加密。**
   - 發生什麼：earendil 團隊（OpenCode / agentic coding infra）發布 blog：原本 inference API 的承諾是「send input, receive output，both are yours」。但 inference provider 正在悄悄破壞這個 property：（a）**reasoning tokens 是 opaque encrypted blobs** — 用戶付費但只能拿到 useless summary；（b）**web search 結果 model 看到 client 看不到** — provider-bound state；（c）**compacted context 只有原 provider 能解密**；（d）**subagent 指令被加密藏在 application 後面**；（e）**file / vector-store / container / cache reference 不能在他處 resolve**；（f）**conversation state keyed by IDs 完全 stored on provider's servers**。結論：「transcript on your machine is no longer your session but a partial view of a session whose operational state belongs to an inference provider」。HN 評論大量呼應：（i）正在為 OpenCode 建 phone app 的開發者說「**I'm reconsidering using my recently acquired Codex sub**」；（ii）已有 agentkanban.io 團隊說明「context capture + reload into new agent sessions，但 **tool use 故意 discard 因為是 proprietary**」 — 反向驗證 portable context 已經有人做出來。
   - 為什麼重要：這是 **portability by design 第一次有 vendor-level 公開質疑**，跟 07-26 Anthropic decoupling 是同一 narrative 不同切角 — Anthropic 講「我們自己拆 decoupling 給用戶」，earendil 講「**其他 vendor 把 session 鎖住，user 拿不到自己的對話**」。對 OpenClaw 結構性意義三層：（a）**OpenClaw session 設計預設 portable transcript** — 對應 07-26 提的「session artifact（append-only log）」，每個 session 結束時存 `sessions/YYYY-MM-DD/session-XXXX.md` 含 tool call / model output / artifact digest / reproduction command；（b）**OpenClaw 不應該用 provider-bound state 來最佳化 context** — agentkanban.io 團隊的選擇（retain context, discard tool use）值得抄：保留 reasoning summary + decisions + artifact，discard encrypted reasoning；（c）**OpenClaw `model-router` 應有 portability test fixture** — 每月跑一次「同一 session transcript 換 provider 能不能繼續工作」簡單 A/B，作為 contract 監測。
   - 來源：<https://earendil.com/posts/session-portability/>、HN <https://news.ycombinator.com/item?id=49118781>。
